# Agent Note: 曲线图上不适用 RC4/RC6（图型标注 + 显式未量测）

Status: implemented

## Problem

全量真实案卷复跑（36 个案卷目录、664 幅页面级 SVG）时，曲线图上的渲染复核发现几乎全是
假阳性：姜辉 `2026-IN-001` 的散点图 图7 报出 43 条——RC6 全部是相邻数据标记
（0.3×1.2 毫米）互相穿过、RC4 是图例符号（短笔画）之间的「剖面线方向相近」。

根因不是判据写错，而是**图型不适用**：曲线图的数据标记与图例符号在设计上就互相叠靠
（密集序列的点必然相邻、图例用短线示意线型），而这两条判据的前提是「闭合轮廓代表零件
边界」「平行短线代表剖面线」。在 `kind: "chart"` 上量测它们，得到的只是噪音——报告会被
淹没，RC6 也永远无法升级为阻断档。

## Decision

绘图侧在**根元素**写 `data-dsh-kind="chart"`（只曲线图写，取值来自 `FigureSpec.kind`），
渲染复核读到它时：

- 不跑 RC4 `hatch-orientation-collision` 与 RC6 `element-overlap`；
- 另记一条 `not-measured`（RC0，info）明示「该图型上这两类判据未量测」，RC1/RC2/RC3/RC5/RC7
  照常量测——「没判」不能看起来像「判过且无问题」（AGENTS 第 11 条）；
- 落版页在页面根元素原样带上该标注（`submission-page.ts`），页级复核同样识别图型；
- 外部 SVG 不带该属性，按「图型未知」处理，全部判据照旧参与。

为什么写进产物而不是加调用参数：交付后回读（`figure-gate` 的漂移检测、`patent_figure_check`
对已交付文件）**只有 SVG 这一个输入**，调用参数在那时已经不存在；写进根元素才能让同一条
产物在生成期、交付期、页级复核三处得到同一结论。

## Alternatives considered

- **给 `checkFigureRendering` 加 `figureKind` 选项、由调用方传入** — 生成期能传（手上有
  `FigureSpec`），但交付后回读时调用方已不知道图型（`readbackSvgFigures` 只能用占位
  `flowchart`），曲线图在门禁上仍会被刷屏——正好是最需要安静的那条路径。
- **按几何特征自动识别曲线图**（坐标轴线 + 刻度 + 数据标记）— 启发式识别本身就是新判据，
  误判会让判据在错误的图上静默不跑；真实曲线图也常缺刻度或复用 `polyline` 画折线，
  特征不稳定。
- **只在生成期跳过、不记 `not-measured`** — 报告里"没有这两类发现"会被读成"已核验无问题"，
  与 AGENTS 第 11 条「降级但不静默」冲突。
- **给所有图型都写 `data-dsh-kind`** — 其余图型没有豁免判据，写与不写不改变任何结论，
  只会让全部既有产物与快照的字节发生变化；只给曲线图写，改动面最小。
- **在 `kind: "chart"` 上整体跳过渲染复核** — 会连带丢掉 RC7（刻度值与轴标目的字高是曲线图
  唯一真实的法域合规风险）与 RC5（越出画布）这两类确有价值的量测。

## Consequences

- 曲线图不再产出 RC4/RC6 噪音，报告里出现一条明确的 `not-measured`，覆盖范围可区分。
- 曲线图的产物字节发生变化（根元素多一个属性）；非曲线图产物逐字节不变。落版页只在
  源图形带标注时多带一个属性。
- 已交付的历史曲线图（生成于本次改动之前）没有该标注，仍会按「图型未知」全量参与——
  这些文件要重新生成才会获得豁免；这是有意的：从 SVG 无法证明它们是曲线图。
- RC6/RC7 仍为 `warn`；本改动不改变级别，只改变曲线图上的适用性。
