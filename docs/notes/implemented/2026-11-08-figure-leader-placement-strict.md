# Agent Note: 图外引线择位改为评分加有界回溯，CAD 通路 fail-closed

Status: implemented

## Problem

`leader-line.ts` 原先是 8 个相对角 × 固定长度步进的贪心首适配：取第一个通过判据的落位，
不回溯。标号一密，先放下的最优方向会堵死后放者的唯一口袋，引擎只能把标号退化成压在零件上的
就地标注。CAD 与示意图共用这一出口，结构图也会交出一张标记线缺失的图，只在 C11 上留一句警告。

引线本身是单段射线，正水平/正垂直时容易和轴对齐的轮廓印成一条线。

## Decision

择位网格改为 12 个绝对方向（相位 15°、步长 30°，避开 0/90/180/270）× 至多 4 档环距。
折线是锚点 → 可选肘点 → 水平短划 → 标号；短划停在与 `glyphBox` 相同的字框外缘再退间隙。
候选先过静态硬拒绝（越界、压盖障碍、与主线条共线），再过动态硬拒绝（已放标号与引线），
按长度、首选方向偏离、擦边、拥挤四项命名权重取最小分。放不下时最多回改 3 轮次优候选，
搜索节点另有上限。

`mode` 分成两档：缺省 `degrade` 仍退化为就地标号并告警（示意图不因一个标号整图失败）；
CAD 渲染传入 `strict`，耗尽则抛 `LeaderPlacementError`，列出放不下的 id。工具把该错误收成
C13，说明减少标记、拆图或用 `label_offset_mm` 钉死偏移。钉死偏移只审计、不改写。

投影边过多时按 `CAD_LEADER_SEGMENT_CAP` 保留最长段并补轴对齐包络。成功出图的 sidecar 写入
最终 `offset_mm`、`degraded` 与 `strict_failure: false`。这是可选字段，不升 sidecar 版本：
解析器仍只校验 version / figures / spec.nodes，旧文件照旧可读；升版本会把已有 sidecar 全部判废。

## Alternatives considered

- **继续贪心首适配，只把方向加密**——落选：方向变多仍不回头，先占坑的标号照样堵死唯一口袋。
- **全局最优（一次求解全部标号）**——落选：搜索没有自然的停机界，确定性和「为什么是这个位置」
  都会变差。3 轮回溯加节点上限把代价圈死，密集但可解的图能回头，不可解的图 fail-closed。
- **CAD 也保持 degrade**——落选：结构图的就地标号压在轮廓上，交付物已经是坏的。示意图节点
  文字本来就在框内，突然全部 strict 会让流程图成批失败，所以 degrade 只留在缺省档。
- **把 china-patent-figure-skill 整库引进**——落选：那个仓库的运行时与 Sati 的抽象几何入口
  不是同一条通路。这里只借用「多方向、多环、评分、有界回溯、严格失败」的语义，不引入依赖。
- **升 sidecar 版本以承载 offset**——落选：新字段可选，旧解析器不读它也不会误判。版本号是
  硬相等检查，升一版等于宣布存量 sidecar 非法。
- **钉死偏移也改成肘点折线**——落选：钉死是调用方给的坐标，改形状就等于改写指令。审计照旧。
- **按几何原语 / 择位搜索拆分 `leader-line.ts`，以避开 800 行上限**——暂缓：拆分要同时挪动
  `LeaderGeometry`、候选生成与回溯状态，与本次行为改动混在一个 PR 里，评审无法区分「搬家」
  与「改逻辑」。改为登记存量豁免，拆分留作独立重构。

## Consequences

- **换来的**：可解的拥挤标号会回头让位；CAD 在放不下时不出图，错误信息直接写明减少标记、
  拆图或钉死偏移。斜段不再与轴对齐轮廓共线。预留带按「环距 + 短划 + 字框」留边，避免
  strict 把本来放得下的标号裁掉。
- **付出的**：有标注的 CAD 图坐标与旧版不再逐位一致（无标注的图不变）。原先「锚点远在零件
  之外仍画出越界标号、再靠 C8 警告」的路径，在候选全部越出画幅时改为 C13 失败。
- **未做**：HLR、爆炸图、DXF，以及把示意图的节点文字改成外引。那些不在这次的范围内。
- **登记的一笔新债**：`leader-line.ts` 增至 980 行，超过 `check-architecture-boundaries` 的
  800 行上限，已登记进 `docs/technical-debt/architecture-baseline.json`（file-size 豁免）。
  拆分方案见上一节的取舍。
