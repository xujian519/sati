# Agent Note: 外观设计二维视图（appearance_view）**明确不做** —— 决策与关闭

Status: implemented

## Problem

批次 B-1/B-2/B-3 逐轮把 `TD-PATENT-N39` 收敛到只剩最后一项：**外观设计二维视图**
（DSH 的 `appearance-view-sheet.ts`，368 行 —— 三维外观的第一角/第三角六面视图版面组合）。

本轮决策：**明确不做**，并关闭该载体。

## Decision

### 不做的依据（四条，按可靠性排序）

1. **外观设计专利的附图主体是照片/图片，不是线条视图。**
   实务口径上，外观案要比对的是**照片本身**（比例尺、投影面积占比、渲染分辨率都是照片口径），
   而且**派生量不入提交件**（比例、面积占比一类数据写在提交件里反而会成为自证风险）。
   ⇒ 「把三维外观画成二维线条视图」既不是提交必需形态，也不是实务的主场景。

2. **DSH 自己也没解决「谁来画图」。**
   DSH 的 `appearance-view-sheet` **只做版面组合、不画图**（调用方给毫米坐标片段，模块负责
   按第一角/第三角投影惯例排布六面、统一缩放比、把视图名标在正下方）。
   ⇒ 引入它等于引入一个「版面排布器」，而线条轮廓从哪来仍然要另找来源——**引入它并不
   闭合外观出图链路**，却要付一次重录窗口的代价。

3. **本仓已有覆盖「外观主场景」的现成路径。**
   外观案真正需要的两件事，本仓都有：`patent_figure_annotate`（在既有图/照片形态的 SVG 上
   补写附图标记并回读核验）与 `analyze_patent_figure`（识图 + 生成专利格式的附图说明文字 +
   标记一致性核对）。外部工具出的照片/线条图进来后，用前者补标号即可。

4. **成本与收益不对称。**
   做它要：新渲染器 + 一次 fixture 重录窗口 + **外观设计专属的像素与比例规则**（照片有阴影、
   灰度、渲染噪声，本仓现有像素门禁是为线条图写的：b/w 判定、线宽下限、DPI/纸面尺寸——
   照片类要另立一套规则，不能顺手复用）。相比之下，`TD-PATENT-N38`（描述预算重排）是**确定
   要做且能持续受益**的工程。

### 边界声明（诚实，不夸大）

- 本仓**不产出**外观设计专用的二维线条视图；能力清单里**不写**这项。
- 本仓现有像素门禁面向**线条图**；**照片类附图未做专门判据** ⇒ 对外观案的照片，本仓提供的是
  「补标号 + 识图核对」，**不是**照片合规判定（未量测的事不说成已通过）。
- 外部工具出的外观图进本仓时，用 `patent_figure_annotate` 补标号并回读核验；**CAD 投影线图
  不得用作外观设计图片**（既有口径，见 `docs/patent-figure-hardening-plan.md`）。

### 触发重做的条件（写清，避免「以后再说」变遗失）

若出现下列任一情形，单独立项（届时须**先核验外观设计的官方文本与像素/比例规则**，再动手）：
- 用户明确要「外观线条视图」；
- 某个案件明确要求**非照片**附图（如审查员要求线条图或六面视图）。

## Alternatives considered

- **先做一个「够用版」的外观视图（只排版、不画图，照搬 DSH 边界）** —— 否决。它不闭合链路
  （轮廓仍缺来源），却要付一次重录窗口；且会让能力清单出现「有外观视图工具」但实际画不出图的
  假象（仓库纪律：不得对外宣称「已具备该能力」）。
- **把外观二维视图挪进 CAD 通路（用 STEP 投影出六面）** —— 否决。CAD 投影线图是**结构图**，
  外观设计要的恰恰不是结构表达；且既有口径已明确「CAD 投影图不得用作外观设计图片」。
- **做成 `kind` 枚举值但先不实现渲染器** —— 否决。那是 B-1 判定过的「接口欺骗」：模型传了
  会落到默认分支出错图。
- **继续挂在 backlog 上等以后做** —— 否决。用户已明确不做；挂着不做的载体只会在下一次盘点时
  被当成「待办」重新讨论，浪费决策带宽（且与「降级但不静默」不同——这是**范围决策**，不是能力
  缺口，应当一次性说清并关闭）。

## Consequences

- **`TD-PATENT-N39` 关闭**（时序图 / 电路图 / 多面板 / 2D 剖视均已落地，外观设计二维视图明确
  不做）⇒ 批次 B-1 原清单 10 项 + B-2/B-3 的两项新图型与多面板，**全部有明确结论**。
- 本仓与 DSH 在**外观二维视图**这一点上**保留差距**（不补）——这是**范围决策**，不是遗漏，
  已在本 note 与 backlog 双处留痕。
- 资源转向确定要做的工程：`TD-PATENT-N38`（patent 域描述预算重排；当前余量仅 200 字符）。
