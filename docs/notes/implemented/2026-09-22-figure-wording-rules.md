# Agent Note: 图面用语规则 V12/V13/V14（wording-rules）

Status: implemented

## Problem

校验器对"图面写了什么"只有一条规则：V5 判 label 超长/多行（疑似注释性段落）。而补正通知书里最常见的图面缺陷恰恰是**短**的：`注：`/`说明：` 前缀、`如图1所示` 这类正文引用、`20mm`/`比例 1:2` 这类标注、句末句号、把图号画进图面、图面词语用英文、标号写成 `20a` 或 `(20)`。这些都不触发 V5，等于整类缺陷无覆盖。

## Decision

新增 `src/patent/figuregen/wording-rules.ts`（纯函数）+ `check.ts` 三条规则，**只吃图面词语**（节点 label + 边标签），不吃说明书正文（正文侧括号规则已由 V10/V11 覆盖）：

| 规则 | 内容 | 依据（已核验） | 生效法域 | 级别 |
|---|---|---|---|---|
| V12 | 注释前缀 / 正文引用 / 尺寸标注 / 比例标注 / 句末标点 / 图号入图 | 细则第 21 条第 3 款 + 指南一部一章 4.3；比例标注另有 PCT 指南 IP 5.150、37 CFR 1.84(k) | 全部（**比例项仅非 cn**） | warn |
| V13 | 图面词语非中文 | 指南一部一章 4.3「附图中的词语应当使用中文，必要时可以在其后的括号里注明原文」 | **仅 cn** | warn |
| V14 | 标号带（小写）字母后缀 / 标号与括号·引号·圈号连用 | 指南一部一章 4.3「附图标记应当使用阿拉伯数字编号」；括号连用另有 PCT Rule 11.13(e)、37 CFR 1.84(p)(1) | 后缀：全部；**括号连用仅非 cn** | warn |

防误伤实现要点：括号内内容先剔除再判非中文（4.3 明文允许"括号里注明原文"，`控制器(controller)` 不报）；全大写词元与计量单位符号放行（`CPU`/`I2C`/`24V`/`100ms`）；`式(1)`/`步骤(1)`/`图(1)` 类编号排除在括号连用之外（与 V11 同源排除）；证据行按规则聚合、上限 15 条并注明余量。

**有意不判三类**（写在模块头注，防后人"顺手补齐"）：`S101` 式步骤标号（不是附图标记，且 `cn-drawing-rules.md` §3 登记为方法步骤的既有代理惯例）；大写字母后缀 `20A`（37 CFR 1.84(u)(1) 与 PCT 指南 IP 5.141 **明文允许**"same number followed by a capital letter"表示部分视图，如 Fig. 7B）；量纲/技术词 `24V`/`3D`/`5G`（与标号同形，无上下文无法区分）。

## Alternatives considered

- **照 deepseek-harness 那样合成一条 `wording-rules` 大规则** — 落选。三类规则的**法域适用性不同**（非中文只在 cn 成立、括号连用只在域外成立），合成一条就无法分别豁免；`FigureCheckFinding` 已有 `rule`/`severity`/`evidence` 结构，规则粒度越细报告越好用（用户可只关一条）。
- **V13（非中文）在 us 模式也判** — 落选。`us` 模式是为出海申请服务的（`brief.ts` 输出英文 BRIEF DESCRIPTION、图号用 `FIG. N`），其图面词语本应为英文；在 us 下判"非中文"会把该模式的**全部正常产物**判成 warn。
- **V14 的括号连用也在 cn 判** — 落选。CN 条文（细则 21 条、指南一部一章 4.3）均**未**禁止括号括住标记，而 Sati 自家的图面惯用形就是 `处理模块(20)`（`render-svg` 据此渲染、`check` 的 `normalizeRefLabel` 据此归一）——对 cn 判这条等于给全库默认写法全量报 warn。改法：把"同一份图若也用于 PCT/US 申请，图面不得写 `(20)`"写进 `references/uspto-drawing-rules.md`（**规则判不了的地方用文档约束**）。
- **判 `S101` 式步骤标号（指南 4.3 要求"阿拉伯数字编号"）** — 落选。步骤标号不承载 `ref`，不是附图标记；CN 实务中流程图用 `S101` 极其常见，且 `cn-drawing-rules.md` §3 自己就把它登记为惯例。对每张流程图报一遍会让真缺陷淹在噪音里。
- **判大写字母后缀 `20A`** — 落选。37 CFR 1.84(u)(1) 与 PCT 指南 IP 5.141 都把"同一编号 + 大写字母"作为**部分视图的合法写法**（Fig. 7B）；判它会与该法域明文冲突。只判小写后缀（`20a`）。
- **判 `24V`/`3D`/`5G` 这类量纲词** — 落选。它们与"数字 + 字母后缀标号"完全同形，无上下文无法区分，判了就是固定误报源。
- **把 V12 的尺寸/比例标注依据写作 PCT Rule 11.13(d)** — 落选（并已在代码注释里显式警告）。核验 Rule 11.13(d) 原文为"比例若在图中给出，应当以图形表示"，**并未禁止标注**；"Indications such as actual size or scale ½ … are not permitted"的落点是 **PCT 指南 IP 5.150**（对 Rule 11.13(c) 的释义）。引用错了条文号会让规则底座被架空。

## Consequences

- 三条规则均为 **warn**，不改变 `ok`/fail 判定，不阻断撰写；`patent_figure_check` 与 `figure-gate` 的报告里按 `[WARN] V12/V13/V14` 出现。
- 每图每规则最多 15 条证据行（超出只报"另有 N 处同类命中"），长图不会淹没报告。
- `处理模块(20)` 在 **us 模式**下会报 V14（这是本条规则的意义所在）；已在 `references/uspto-drawing-rules.md` 补写"PCT/US 图面不得写 `(20)`"，让改法与依据同一处可查。
- 规则只提示、不改写输入：修不修由代理师决定，本模块不自动重写标签。
- 新增 11 例测试（`tests/patent/figuregen/wording.spec.ts`），其中半数以上是防误伤断言。
