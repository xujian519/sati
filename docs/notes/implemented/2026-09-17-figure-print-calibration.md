# 附图阈值的打印实测：先做校准页（仪器），阈值等实测回填

Status: implemented（2026-09-17；仪器落地，**阈值回填待打印实测**）
Scope: `scripts/figure-print-calibration.ts`、`tests/scripts/figure-print-calibration.spec.ts`

## Problem

附图链路里几个阈值是**推导值**，没有在本机打印/复印/扫描链路上验证过：

| 常量 | 现值 | 现依据 |
|---|---|---|
| `MIN_PRINTED_FONT_MM` | 2.0mm | 指南一部一章 4.3"缩小到三分之二仍应能清晰分辨"的纸面换算 + 常用代理实践 |
| `CAD_LINE_WIDTH_MM` | 0.35mm | 专利附图线条 0.25–0.5mm 的惯用区间取中 |
| `CAD_HATCH_LINE_WIDTH_MM` | 0.2mm | 剖面线为细实线（相对轮廓线更细）的惯用关系 |
| `PIXEL_MID_GRAY_RANGE` / `PIXEL_WHITE_MIN` | [50,205] / 245 | 8 位灰度下"中间灰/近白"的经验区间 |
| `PIXEL_MIN_DPI`–`PIXEL_MAX_DPI` | 72–300 | 栅格化充足性与"上游误标 DPI"的经验区间 |

这些数字决定"图能不能交付"（V7 字高 warn、C6 剖面线可辨、栅格门禁黑白性/线宽判定），
却与真实打印机、纸张、复印机、扫描仪的实际分辨能力脱钩——而**实测又需要一台打印机**，
不是代码能独立完成的事。于是出现一个真空：既不能凭猜改阈值，也不该一直挂着"待验证"。

## Decision

**先造仪器，再等测量结果**：新增 `scripts/figure-print-calibration.ts`，输出一张 A4 校准页，
把上述每个阈值排成**可勾选的档位**：

- 字高两行：原尺寸与 **2/3 缩小**各一套（1.2/1.4/1.6/1.8/2.0/2.2/2.5/3.0mm 及其 2/3），
  直接对应指南的三分之二判据；
- 线宽带：0.10–0.50mm 七档，含轮廓线当前值；
- 隐藏线虚线样张与**真实参数的剖面线样块**（0.2mm / 2.5mm 间距 / 45°）；
- 平行线最小可分辨间距：0.10–0.80mm 六档（为将来可能的"最小线间距"判据取实测）；
- 灰阶条：0–255 的 11 档，覆盖中间灰区间两端与"近白"阈值。

纪律：**档位与文案全部取自源码常量**（`page-contract` / `render-cad` / `pixel-gate`），
并有单测断言"页面上的档位来自常量"——常量改了校准页跟着变，不会校准到过期数字上。
**在实测结果回来之前，阈值保持不变**（不用另一组猜测替换这一组猜测）。

## Alternatives considered

- **按纸张物理模型重算阈值（网点扩散/调制传递函数等）** — 落选：模型里的系数（墨点扩散、
  纸张吸墨、复印增益）本身只能实测得到，等于把一组猜测换成另一组猜测。
- **维持现状：按 DPI/像素换算代理物理量** — 落选：这正是要修的问题（V7 从画幅像素改成纸面
  毫米就是为了断开这种脱钩），继续用它给出的阈值没有意义。
- **让使用者在任意样张上目测"能不能看清"** — 落选：没有标尺也没有档位，结论既不可比对也不可复现，
  无法据此改常量。
- **引入"扫描仪 API + 图像分析"自动闭环** — 落选（本次不做）：打印机/扫描仪型号与驱动差异极大，
  属环境相关测量，不适合进自动化门禁（本仓的单测不依赖本机硬件是既定纪律）；先人工读表回填。
- **把校准页做成 PDF（Chrome headless 打印）** — 落选：SVG 用毫米单位，浏览器 100% 打印即 1:1；
  再经一次 PDF 渲染会引入第二次版式/线宽处理，而测量对象应与交付物同源。
- **把档位数字写死在文档里（页面与代码脱钩）** — 落选：会校准到过期数字；改为从常量生成 +
  单测断言档位来源。
- **把这页并入附图门/工具，作为运行时产物** — 落选：它是**一次性的标定仪器**，不是交付物；
  混进工具面会污染模型可见的工具语义与 schema（并触发 fixture 重录）。

## Consequences

- **阈值维持推导值**，直到有人打印并回报实测（回填点：上表五个常量 + 本 note 的表格）。
  回填时须同时更新 `docs/patent-figure-hardening-plan.md` 与本 note 的状态行。
- 校准页**刻意含灰色**（灰阶条）与多种线宽：它是测量工具，不是交付附图；交付契约
  （仅 `#000000`/`#FFFFFF`）不受影响，两者不要混为一谈。
- 未做：自动化扫描分析闭环；纸张/复印机型号矩阵；彩色打印链路的颜色判定（本模块只做黑白交付）。
