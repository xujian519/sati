## 卡片内容

### 核心要点

**重要术语澄清**：专利法实施细则第54条规定的**"公众意见"程序**，在专利代理人实务中常被称为**"公众异议"**。

虽然中国专利法在2000年已取消正式的"异议程序"，但代理人行业仍习惯用"公众异议"指代第54条的公众意见程序。

---

### 法律依据

**专利法实施细则第54条**：
> 自发明专利申请公布之日起至公告授予专利权之日止，任何人均可以对不符合专利法规定的专利申请向国务院专利行政部门提出意见，并说明理由。

---

### 程序特点

| 特点 | 说明 |
|------|------|
| **时间窗口** | 申请公布后（18个月）→ 授权公告前 |
| **提出主体** | 任何人（不限资格） |
| **费用** | 免费 |
| **审查主体** | 国家知识产权局实质审查部门 |
| **法律效力** | 供审查员参考，非强制性 |
| **救济途径** | 无独立救济途径 |

---

### "不符合专利法规定"的具体情形

#### 1. 实质授权条件（最常见）

- **新颖性**（第22条第2款）- 属于现有技术
- **创造性**（第22条第3款）- 显而易见、缺乏技术启示
- **实用性**（第22条第4款）- 无法制造或使用
- **说明书充分公开**（第26条第3款）- 所属技术人员无法实现
- **权利要求清楚**（第26条第4款）- 保护范围不明确
- **权利要求以说明书为依据**（第26条第4款）- 概括过宽或过窄
- **必要技术特征**（实施细则第20条第3款）- 缺少解决技术问题的必要特征

#### 2. 授权客体问题

- 属于科学发现、智力活动规则、疾病诊断治疗方法等（第25条）
- 违反法律、社会公德或公共利益（第5条）

#### 3. 程序性问题

- 修改超范围（第33条）
- 缺乏单一性（第31条第1款）
- 同样的发明创造重复授权（第9条第1款）
- 依赖遗传资源未披露来源（第26条第5款）

### 实务操作要点

#### 提交时机

**最佳时机**：收到审查意见通知书后、授权公告前

原因：
- 此时审查员已形成初步审查意见
- 公众意见可影响审查员的最终判断
- 有足够时间准备对比文件和意见陈述

#### 意见书撰写

**必备要素**：
1. **专利申请信息**：申请号、发明名称、申请人
2. **具体法律依据**：明确指出违反专利法哪条规定
3. **详细理由说明**：逐条分析为何不符合规定
4. **证据支持**：对比文件、公知常识证明等
5. **结论建议**：建议驳回或要求申请人修改

**撰写技巧**：
- 语言客观、理性，避免情绪化表达
- 重点突出创造性、新颖性问题（最常见、最有效）
- 对比文件选择与申请最接近的现有技术
- 如有国外同族专利被驳回，提供驳回决定作为参考

#### 提交方式

- **电子提交**：通过国家知识产权局电子申请系统（CPC客户端）
- **纸质提交**：邮寄或现场递交（不推荐）
- **接收部门**：实质审查部门（具体审查员）

### 与"异议程序"的历史区别

| 对比项 | 公众意见（现行） | 异议程序（1984-1992） |
|--------|-----------------|---------------------|
| **提出时间** | 授权前（公布后） | 授权前（公告后3个月内） |
| **法律地位** | 非正式程序 | 正式法律程序 |
| **审查效力** | 供参考，非强制 | 必须审查并答复 |
| **救济途径** | 无 | 可申请复审 |
| **费用** | 免费 | 需缴纳异议费 |
| **现状** | ✅ 现行制度 | ❌ 1992年已取消 |

### 行业惯例与术语

#### 代理人术语

| 正式术语 | 行业俗称 | 使用场景 |
|---------|---------|---------|
| 公众意见程序 | **公众异议** | 实务交流、客户沟通 |
| 实质审查 | **实审** | 日常沟通 |
| 授权公告 | **授权** | 简称 |
| 审查意见通知书 |**一审意见**/**二审意见** | 按审查轮次 |

#### 注意事项

⚠️ **在正式法律文件中应使用"公众意见"而非"公众异议"**
⚠️ **在客户沟通和行业交流中可用"公众异议"但需明确指代第54条**
⚠️ **避免与历史上已取消的"异议程序"混淆**

### 实务案例场景

#### 场景1：竞争对手申请专利

**情况**：竞争对手的发明专利申请公布，技术方案与本公司产品相近

**策略**：
1. 组织技术团队分析专利申请
2. 检索现有技术（优先检索本公司技术文档、公开产品）
3. 如发现缺乏新颖性/创造性，及时提出公众意见
4. 阻止或延迟竞争对手获得专利权

#### 场景2：客户关注的技术领域

**情况**：客户发现某项技术的专利申请可能影响其业务

**策略**：
1. 评估该专利授权对客户的影响程度
2. 如影响重大，建议提出公众意见
3. 重点分析技术方案的显而易见性
4. 提供详细对比分析报告

#### 场景3：专利质量明显存在问题

**情况**：某专利申请存在明显撰写缺陷或技术方案明显缺乏创造性

**策略**：
1. 作为行业专业人士，有义务提高专利质量
2. 提出建设性公众意见
3. 帮助审查员发现可能存在的问题
4. 维护专利制度的公正性

### 优势与局限

#### ✅ 优势

1. **成本低** - 无需缴纳费用
2. **门槛低** - 任何人都可以提出
3. **灵活性高** - 可在任何授权前阶段提出
4. **保密性好** - 提意见人身份保密
5. **不影响后续程序** - 即使不采纳，仍可后续提出无效宣告

#### ⚠️ 局限

1. **非强制性** - 审查员可以不采纳
2. **无独立程序** - 附属于实质审查程序
3. **无救济途径** - 对处理结果不能单独起诉
4. **时间敏感** - 必须在授权前提出
5. **证据要求高** - 需要充分证据支持
