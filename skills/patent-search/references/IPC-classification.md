# IPC 国际专利分类表

## IPC 分类体系结构

IPC 分类号由以下部分组成：
- **部** (Section): A-H，共 8 个
- **大类** (Class): 两位数字
- **小类** (Subclass): 大写字母
- **大组** (Group): 1-3 位数字
- **小组** (Subgroup): 斜杠 + 数字

**示例**: `F23B 10/00`
- F = 机械工程部
- 23 = 燃烧设备大类
- B = 燃烧方法小类
- 10/00 = 只燃烧固体燃料的大组

## 检索建议

### 1. 精确限定 IPC
在 Google Patents 中使用 `ipc:` 前缀：
```
ipc:C10J OR ipc:F23B OR ipc:F24B
```

### 2. 组合关键词和 IPC
```
(生物质气化炉 OR 气化装置) AND (ipc:C10J OR ipc:F23B)
```

### 3. 扩展同义词
- 气化炉 / 气化装置 / 气化设备
- 生物质 / 生物燃料 / 秸秆 / 木屑
- 双出口 / 分段 / 两段式 / 多出口
