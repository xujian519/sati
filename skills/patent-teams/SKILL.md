# 专利团队角色集

本目录收录 Sati 团队编排层的专利场景**角色成员**（各子目录为 `type: role` 的 SKILL.md），按作业类型分组：立案包、撰写包、答复审查意见包、补正包、复审包、无效宣告包（请求人×专利权人+合议组）、侵权诉讼包（专利权人×被告代理人+裁判+可选技术调查官）。

- 每个子目录是一个角色（场景/立场/职责/系统提示），可由 `team_add_member` 以 role id 引用。
- 由主会话（captain）用 `team_*` 工具组建团队并按 DAG 依赖调度。
- 涉及法条、判例或专利实务要点时，用 `patent_wiki_search` / `patent_case_search` / `law_search` 核实，不凭记忆。

> 角色注册装配由团队编排层后台扫描 `skills/` 下 `type: role` 的 SKILL.md 完成（参照 Sati 团队编排层约定）。
