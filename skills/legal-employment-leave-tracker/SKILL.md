# /legal-employment-leave-tracker

检查所有有法定硬性截止日期的进行中假期，仅呈现需要决策或行动的项目。不是状态面板——告诉你需要做什么及为什么。

## 指令

1. 加载 `./.legal/practice/employment-legal.md` → 管辖地表和假期管理部分。

2. 如果 `./.legal/employment-legal/leave-register.yaml` 不存在或无数据，提示律师上传假期电子表格或使用 `/legal-employment-log-leave` 添加条目。

3. 仅对需要行动的假期发出预警。无问题的假期每项一行总结。

4. 检查以下截止日期类型：

| 假期类型 | 关键截止日期 | 法律依据 |
|---|---|---|
| 医疗期 | 医疗期满日（按工作年限3-24个月） | 企业职工患病或非因工负伤医疗期规定 `[法条原文]` |
| 产假 | 产假期满日（98天基础 + 省/直辖市奖励假） | 女职工劳动保护特别规定 `[法条原文]` |
| 年休假 | 年末未休结转截止（一般不跨年结转） | 职工带薪年休假条例第5条 `[法条原文]` |
| 工伤假 | 停工留薪期满日（一般不超过12个月） | 工伤保险条例第33条 `[法条原文]` |
| 婚假 | 各省/直辖市人口与计划生育条例规定 | 省/直辖市规定 |

## 示例

```
/legal-employment-leave-tracker
```

建议每周运行——设置周一上午提醒调用 `/legal-employment-leave-tracker`。自动排期需要单独的集成（日历提醒、定时任务等）；本模式不自行排期；需要时用 `tool-schedule` 建立提醒。

## Sati 检索接线

- 在本项目中，法条原文优先用 `law_search` 检索（宝宸知识库，含法律层级过滤与现行/失效标注）；引用成稿前用 `law_verify` 逐条做形式核验。
- `law_search` / `law_verify` 不可用或未命中时，如实标注「未检索到 / 未做形式核验」，不得以模型记忆补法条。
