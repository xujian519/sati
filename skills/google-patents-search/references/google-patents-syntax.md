# Google Patents 检索语法参考

## 基础检索语法

### 1. 关键词检索
- 单个关键词：`穿刺`
- 多个关键词（AND）：`穿刺 AND 模型`（默认关系）
- 或关系（OR）：`穿刺 OR 注射`
- 排除（NOT）：`穿刺 NOT 手术`

### 2. 短语检索
- 精确匹配：`"骨髓腔输液"`
- 完整短语搜索，顺序敏感

### 3. 通配符
- 单词补全：`穿刺*`（匹配穿刺针、穿刺技术等）
- 中间通配：`*穿刺*`（包含穿刺的所有词）

## 高级检索字段

### 申请人/专利权人
```
assignee:"华为技术"
assignee:("华为" OR "中兴")
```

### 发明人
```
inventor:"张三"
inventor:("张三" OR "李四")
```

### 专利号
- 公开号/公告号：直接输入专利号
```
CN115012345A
US2023001234A1
EP4123456A1
```

### 分类号
- IPC分类号：
```
IPC:A61B17/34
IPC:(A61B17/34 OR A61M5/00)
```

- CPC分类号：
```
CPC:A61B17/34
CPC:(A61B17 OR A61M5)
```

### 日期范围
- 申请日：
```
before:2023-01-01
after:2020-01-01
```

- 公开日：
```
publication:2020..2023
```

### 专利状态
- 已授权：`status:GRANT`
- 申请中：`status:PENDING`

### 专利类型
- 授权专利：`type:PATENT`
- 专利申请：`type:APPLICATION`

## 组合检索示例

### 示例1：按申请人和技术领域检索
```
assignee:("华为" OR "中兴") AND (5G OR 通信)
```

### 示例2：按时间和技术检索
```
("人工智能" OR "机器学习") AND after:2022-01-01 AND before:2024-01-01
```

### 示例3：按分类号和申请人检索
```
CPC:A61B17 AND assignee:"美敦力"
```

### 示例4：复杂布尔逻辑
```
(穿刺 OR 注射) AND (模型 OR 训练) NOT (手术 OR 治疗)
```

## URL参数说明

Google Patents支持通过URL参数进行检索：

### 基础URL
```
https://patents.google.com/
```

### 常用参数
- `q`: 查询词或检索式
- `assignee`: 申请人过滤
- `inventor`: 发明人过滤
- `before`: 截止日期
- `after`: 起始日期
- `cpc`: CPC分类号
- `ipc`: IPC分类号
- `status`: GRANT/PENDING
- `type`: PATENT/APPLICATION
- `num`: 返回结果数量（默认10，最大100）
- `sort`: 排序方式（new, old, relevance）

### URL示例
```
https://patents.google.com/?q=穿刺+模型&assignee=华为&after=2020-01-01&num=50
```

## 检索策略建议

### 1. 从宽到窄
- 先用宽泛的关键词检索
- 根据结果逐步添加限制条件

### 2. 同义词扩展
- 考虑技术术语的不同表达
- 使用OR连接同义词

### 3. 分类号辅助
- 找到相关专利的分类号
- 用分类号扩大检索范围

### 4. 申请人检索
- 关注主要竞争对手
- 结合技术领域和申请人

## 注意事项

1. **中文检索**：Google Patents对中文支持良好
2. **英文检索**：技术专利建议用英文关键词
3. **专利号格式**：注意公开号和授权号的区别
4. **日期格式**：统一使用YYYY-MM-DD格式
5. **布尔运算符**：AND、OR、NOT必须大写
