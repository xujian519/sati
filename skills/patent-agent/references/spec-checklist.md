# 说明书检查清单

> 用于专利说明书撰写完成后的逐项质量自查。与自动质量预检配合使用。

## 一、结构完整性

- [ ] **五部分齐全**：技术领域、背景技术、发明内容、附图说明、具体实施方式五部分均存在
- [ ] **各部分界限清晰**：各章节有明显标题分隔，内容不混入其他章节
- [ ] **发明名称准确**：说明书首页的发明名称与技术领域一致，不超过 25 字

## 二、清楚性

- [ ] **技术领域定位准确**：写明要求保护的技术方案所属的技术领域，非广义领域
- [ ] **背景技术引用完整**：引证反映本申请技术方案背景的现有技术文件，注明出处
- [ ] **发明内容与技术问题对应**：发明内容中记载的技术方案直接对应要解决的技术问题
- [ ] **技术问题、方案、效果三段式完整**：问题 → 方案 → 效果逻辑链完整
- [ ] **有益效果有依据**：有益效果与区别技术特征对应，有对比实验或理论推导支撑
- [ ] **术语统一**：全文使用同一术语指代同一技术特征，不自造新词

## 三、支持性

- [ ] **实施例数量充分**：实施例数量与保护范围匹配，上位概念有多个代表性实施例
- [ ] **数值范围有端点实施例**：数值范围的端点值和至少一个中间值有实施例
- [ ] **实施例可再现**：实施例记载的操作步骤、参数、条件等足以让所属领域技术人员实现
- [ ] **效果数据翔实**：实施例有定量效果数据，而非仅定性描述"效果好"
- [ ] **对比例恰当**：有与最接近现有技术的对比实验数据（创造性判断的关键支撑）

## 四、形式规范

- [ ] **附图标记一致性**：说明书中的附图标记与附图中的标记完全一致
- [ ] **附图说明完整**：对每幅附图的图名和表示的内容有简要说明
- [ ] **无超范围内容**：说明书内容未超出原始提交的申请文件记载范围
- [ ] **无禁止性内容**：无违反法律、社会公德或妨害公共利益的表述
- [ ] **格式符合受理要求**：行距、字体、页边距等满足受理局的形式要求

## 五、领域适配

### 机械领域
- [ ] 有整体结构图和各部件细节图
- [ ] 装配关系、运动关系描述清楚
- [ ] 材料选择有依据（如需要）

### 电学领域
- [ ] 电路框图、信号流图完整
- [ ] 连接关系、信号传输路径描述清楚
- [ ] 硬件和软件边界清晰

### 化学领域
- [ ] 制备方法步骤完整
- [ ] 参数（温度、压力、时间、pH 等）范围合理
- [ ] 产物表征数据完整（NMR、MS、IR 等）

### 软件领域
- [ ] 方法步骤与装置/系统对应
- [ ] 模块划分与功能对应
- [ ] 数据流向和处理逻辑清楚

## 评分对照

| 维度 | 对应质量预检维度 | 通过标准 |
|------|------------------|---------|
| 结构完整性 | 结构完整性 | ≥ 3/3 通过 |
| 清楚性 | 内容充分性 | ≥ 4/6 通过 |
| 支持性 | 内容充分性 | ≥ 4/5 通过 |
| 形式规范 | 引用格式 | ≥ 4/5 通过 |
| 领域适配 | — | ≥ 3/4 通过 |
