# 专利术语表（Patent Glossary）

> 来源：YunXi `_shared/patent_glossary`（MIT）适配。全文术语必须按此定义统一使用。

| 术语 | 定义 | 法律依据 |
|------|------|---------|
| 现有技术 | 申请日以前在国内外为公众所知的技术 | 专利法 A22.5 |
| 新颖性 | 不属于现有技术，也无抵触申请 | 专利法 A22.2 |
| 创造性 | 非显而易见 + 实质性特点 + 显著进步 | 专利法 A22.3 |
| 三步法 | 确定最接近现有技术 → 区别特征和实际解决的技术问题 → 技术启示判断 | 审查指南第二部分第四章 |
| 技术启示 | 本领域技术人员是否有动机将区别特征应用于最接近现有技术 | 审查指南第二部分第四章 |
| 充分公开 | 说明书清楚完整，以所属领域技术人员能够实现为准 | 专利法 A26.3 |
| 清楚性 | 权利要求以说明书为依据，清楚简要限定保护范围 | 专利法 A26.4 |
| 单一性 | 一件申请限于一项发明，属于同一发明构思可合案申请 | 专利法 A31.1 |
