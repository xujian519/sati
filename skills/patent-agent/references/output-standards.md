# 输出标准（Output Standards）

> 来源：YunXi `_shared/output_standards`（MIT）适配。所有专利文书与报告的格式基线。

## 法条引用格式

- 统一格式：《专利法》第XX条第X款（第X项）；审查指南第X部分第X章第X节
- 禁止模糊表述："根据专利法的相关规定" → 《专利法》第22条第3款

## 编号层级

`一、 → （一） → 1. → （1） → ①` 逐级缩进，同级编号统一，不得跳级。

## 对比文件引用

- 首次出现：完整信息（如"对比文件1（CN102241592A，下称D1）"）
- 后续引用：统一用 D1 / D2 / D3…

## 术语一致性

- 同一概念全文统一表述，不混用同义词
- 专利术语定义见 `patent-glossary.md`

## 文档引用

- 专利法条文：按版本引用（专利法 2020 修正版、实施细则 2023 修订版）
- 审查指南：标注部分/章节
