# OA 答复检查清单

> 用于审查意见通知书答复撰写完成后的逐项质量自查。

## 一、修改合规性

- [ ] **修改针对审查意见指出的缺陷**：修改内容与审查意见通知书中指出的缺陷直接对应，不是无关联修改
- [ ] **不超范围（A33）**：修改未超出原始提交的申请文件记载的范围
- [ ] **修改方式正确**：权利要求修改符合当地修改方式要求（如中国：不得超出原权利要求书和说明书记载范围）
- [ ] **主动修改时机合规**：如系主动修改，确认处于允许的主动修改期内
- [ ] **删除式修改有依据**：删除权利要求或技术方案时，确认删除后不违反 A33

## 二、争辩逻辑

- [ ] **区分事实认定与法律适用**：明确区分审查意见是事实认定错误还是法律适用错误
- [ ] **对比文件区分明确**：明确区分本申请与各对比文件的技术区别，不笼统争辩
- [ ] **逐条回应**：针对审查意见通知书中指出的每一条缺陷逐一回应，无遗漏
- [ ] **争辩有证据支撑**：争辩性意见附有对比实验数据、引用文献或公知常识性证据
- [ ] **承认与争辩一致**：若部分认可审查意见，明确标注认可的缺陷和不同意争辩的部分
- [ ] **逻辑链闭合**：从争辩起点到结论的逻辑链完整，无跳跃

## 三、对比文件分析

- [ ] **对比文件公开内容引用准确**：引用对比文件的具体段/行/附图标记，非笼统引用
- [ ] **多份对比文件的关系明确**：多份对比文件之间的结合启示或组合基础有说明
- [ ] **技术领域差异区分**：若本申请与对比文件技术领域不同，明确指出
- [ ] **技术效果对比有数据**：本申请与对比文件的技术效果对比有数据支撑
- [ ] **技术偏见/预料不到的技术效果**：如适用，充分说明存在技术偏见或产生了预料不到的技术效果

## 四、形式规范

- [ ] **答复期限未超**：确认答复仍在审查意见通知书规定的期限内
- [ ] **替换页完整**：修改后的权利要求书/说明书提交了完整的替换页
- [ ] **修改标记规范**：修改处有明确的标记（删除线、下划线、高亮等）
- [ ] **附带修改说明**：提交了修改说明（Amendment Remarks），逐条说明修改依据
- [ ] **签字页齐全**：委托书/授权书（如适用）已签署

## 五、策略评估

- [ ] **争辩成本效益合理**：对于难以克服的缺陷，争辩成本（多次答复）与案件价值匹配
- [ ] **辅助修改方案备选**：如主方案被驳回风险较高，准备了辅助修改方案
- [ ] **分案申请已考虑**：如需保留未修改的技术方案，已考虑分案申请
- [ ] **面谈/电话沟通已安排**：对于复杂疑难案件，已考虑安排与审查员面谈或电话沟通
- [ ] **驳回预期有预案**：对驳回的可能性有预判，并准备了复审请求预案

## 常见驳回缺陷对照

| 驳回条款 | 常见场景 | 应对策略 |
|---------|---------|---------|
| A22.2 新颖性 | 权利要求被对比文件全部公开 | 补充区别特征；删除被公开的方案 |
| A22.3 创造性 | 对比文件组合后认为显而易见 | 强调技术偏见/预料不到效果；补充对比实验 |
| A26.3 充分公开 | 实施例不可实现 | 补充可实施证据；限缩保护范围 |
| A26.4 不支持 | 权利要求概括过宽 | 限缩保护范围至有实施例支撑的范围 |
| A33 超范围 | 修改引入新内容 | 删除超范围内容；还原至原始记载 |

> 自查完成后，对答复文本做自动质量预检（结构完整性 + 内容充分性），再提交人工复核 OA 答复质量。
