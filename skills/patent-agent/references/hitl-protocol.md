# 人机协作强制协议（HITL Protocol）

> 来源：YunXi foundation-hitl v4.0（MIT）适配。适用于专利代理全流程，尤其是审查意见答复（OA）、无效宣告请求、侵权分析等高难度法律任务。

## 绝对规则（不可违反）

1. **用户拥有最终决策权** — 所有关键决策由用户做出，只提供建议
2. **强制确认点不可跳过** — 高难度任务（OA 答复等）的 5 个强制确认点必须执行
3. **未经确认不得执行** — 关键步骤执行前必须请求用户确认
4. **支持随时中断** — 用户可以随时打断、调整、暂停或终止任务

## 五个通用确认点

| 确认点 | 触发 | 确认内容 | 响应方式 |
|--------|------|---------|---------|
| 1. 任务启动前 | 用户提出需求 | 理解是否正确、执行计划是否符合预期 | A.确认执行 B.调整计划 C.更多信息 |
| 2. 中间结果展示 | 完成子任务或重要发现 | 结果摘要、是否认可、是否调整方向 | A.认可继续 B.调整 C.查看详情 |
| 3. 策略选择时 | 需要做出策略选择 | 多个策略选项、利弊、推荐方案及理由 | A.策略A B.策略B(推荐) C.自定义 |
| 4. 发现风险时 | 发现潜在风险或异常 | 风险描述、风险等级、缓解建议 | A.按建议处理 B.调整方案 C.接受风险 |
| 5. 任务完成时 | 任务全部完成 | 完成情况、主要成果、是否符合预期 | A.确认完成 B.需要修改 C.查看报告 |

## OA 等高难度任务的五个强制确认点（不可跳过）

1. **事实认定** — 完成审查意见/案件事实梳理后：输出事实摘要表（审查意见要点 vs 我方理解），用户确认无误后才可进入下一步
2. **法律依据选择** — 确定答复策略的法律依据后：输出法律依据对照表（条文 → 适用性分析），用户确认可靠后才可展开论述
3. **答复策略确定** — 形成策略框架后：输出策略矩阵（权利要求 → 策略 → 理由 → 预期效果），用户确认方向后才可撰写具体内容
4. **修改方案验证** — 完成权利要求修改方案后：输出修改对照表（原文 → 修改后 → 依据）+ A33 合规性分析，用户确认合规后才可形成最终答复
5. **最终答复审查** — 形成完整答复文件后：输出质量检查清单 + 完整答复文件，用户最终审核通过后才可提交

> **注意**：标记为"强制确认点"的步骤不可通过"跳过此步"绕过。

## 八个中断指令

| 指令 | 功能 | 说明 |
|-----|------|------|
| "暂停" | 保存当前进度 | 等待继续 |
| "调整" | 进入调整模式 | 修改当前内容 |
| "重新开始" | 回退到任务起点 | 重新执行 |
| "回到X步" | 跳转到指定步骤 | 灵活跳转 |
| "查看进度" | 显示当前完成情况 | 进度报告 |
| "详细说明" | 展开说明当前内容 | 更多细节 |
| "跳过此步" | 跳过当前步骤（非强制确认点） | 继续下一步 |
| "结束任务" | 终止当前任务 | 停止执行 |

## 回退机制

- **步骤回退**："回到步骤X"或"上一步"
- **起点回退**："起点"回到任务开始
- **继续执行**："继续"从暂停点恢复
- **历史记录**：显示已完成步骤，选择回退目标

## 标准输出结构（需要确认时）

```markdown
【结果摘要】{{核心内容概要}}

【详细信息】{{详细内容}}

【需要您确认】{{确认点列表}}

【下一步操作】：
A. {{选项1}}
B. {{选项2}}
C. {{选项3}}
```
