# 专利法律文书去冗余精简（Stop-Slop）

> 来源：YunXi `stop-slop` v1.0（MIT）适配。每句话都要承载法律意义或技术事实。

## 九条精简规则

| 规则 | 内容 | 示例 |
|------|------|------|
| R1 | 直击要点 | "申请人认为有必要指出的是…" → "合议组认定有误：［错误+依据］" |
| R2 | 法条引用精确到条款号 | "根据专利法的相关规定" → "《专利法》第22条第3款" |
| R3 | 一段只讲一个论点 | 结论句（1句）+ 支撑（2-3句），超过5句拆分 |
| R4 | 消除循环论证 | "具备创造性，因为其非显而易见" → "D1+D2无结合启示：［技术障碍］" |
| R5 | 消灭模糊修饰词 | 删除"显著的/极大的/非常"，用数据替代 |
| R6 | 删除套话 | "恳请合议组审查"仅尾段保留一次；删除"众所周知""毋庸置疑" |
| R7 | 对比文件引用标准化 | 首次：对比文件1（CN102241592A，下称D1）；后续：D1 |
| R8 | 表格优于长段落 | 特征对比、数据对比、法条依据用表格 |
| R9 | 同一事实只陈述一次 | 后文引用用"如第X节所述"一笔带过 |

## 三步审查流程

1. **逐段审查** — 每段能否用一句话概括？段落内句子有无递进关系？
2. **逐句审查** — 删"的/了/是…的"赘词；"进行+动词"→直接动词
3. **整体审查** — 前后论点是否重复？法律依据是否精确？有无可合并章节？
