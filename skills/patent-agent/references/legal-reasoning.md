# 法律推理框架（五步三段论）

> 来源：YunXi `_shared/legal_reasoning`（MIT）适配。所有专利/法律分析结论应遵循此推理链，确保可追溯。

1. **识别法律问题** — 从用户查询/案情中提取争议焦点和法律要点
2. **引用相关法条** — 精确到条、款、项，标注来源（法律名称 + 条款编号）
3. **分析技术事实** — 将权利要求逐特征与对比文件比对，不遗漏任何特征
4. **适用法律于事实** — 判断法条规定的构成要件是否满足，逐要件论证
5. **得出结论并标注置信度** — 明确结论，标注 high / medium / low 置信度

## 适用要求

- 每个结论都必须能回溯到第 2-4 步（法条 + 事实 + 适用论证）
- 法条引用不确定时用 `law_search` 核实原文，检索不到不得臆造
- 结论置信度受证据充分性影响：对比文件未公开的特征 → 不得臆断
