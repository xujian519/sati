# /legal-commercial-customize

## 何时运行

用户键入 `/legal-commercial-customize`。他们想修改业务领域配置中的某项——风险姿态、上报联系人、审查指引立场、管辖、输出格式——而无需重新运行完整冷启动访谈。

## 做什么

1. **读取配置。** 读取 `./.legal/practice/commercial-legal.md`。如果不存在或仍有占位符，说：你还没有运行设置。先运行 `/legal-commercial-cold-start-interview`——定制功能用于调整已有的配置。

2. **展示可定制项目清单。** 按组列出配置中的内容：
   - **公司/你是谁** — 名称、行业、法域范围、执业场景
   - **风险姿态** — 保守/中等/激进
   - **人员** — 上报链条、审批人
   - **审查指引立场** — 实质合同立场及其让步方案
   - **保密协议分类偏好**
   - **审查偏好** — 修订风格、说明深度
   - **行文风格**
   - **工作流** — 案件工作区路径、续约提醒节奏
   - **集成** — 电子签章/合同管理系统/飞书/文档存储状态

3. **询问想修改什么。**

4. **进行修改。** 展示当前值、询问新值、说明下游变更影响、确认、写入配置。

   示例：
   - *责任上限让步从12个月→6个月：* "`/legal-commercial-review`现在会将超过6个月的任何条款标注为偏离。"
   - *新的上报审批人：* "任何超出你自身权限的修订现在将路由至此审批人。"

5. **共享配置变更** 写入 `company-profile.md` 并注明该变更影响所有模式。

6. **收尾。** "完成。你的下一个输出将反映该变更。随时可运行 `/legal-commercial-customize`。"

## 防护措施

- **绝不删除任何配置部分。** 如果用户想"移除"某项，设为 `[未配置]`。
- **标注内部不一致。** 如果变更会使配置不一致，标注紧张关系。
- **标注防护措施降级。** 如果用户要求关闭某项防护措施，说明其保护的内容并确认理解风险。
- **一次一项变更。** 不要重新问整个访谈。

## Sati 检索接线

- 在本项目中，法条原文优先用 `law_search` 检索（宝宸知识库，含法律层级过滤与现行/失效标注）；引用成稿前用 `law_verify` 逐条做形式核验。
- `law_search` / `law_verify` 不可用或未命中时，如实标注「未检索到 / 未做形式核验」，不得以模型记忆补法条。
