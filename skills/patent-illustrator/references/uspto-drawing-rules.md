# USPTO 附图规则（出海模式）— 逐条溯源

> 本文是 patent-illustrator 技能 USPTO 模式（`jurisdiction: "us"`）的规则底座。
> 与 CNIPA 模式（[cn-drawing-rules.md](cn-drawing-rules.md)）并立：图号标注改用 "FIG. N"，
> CNIPA 特有规则（摘要附图 V8、实用新型必须有附图 V9）跳过，违规信息引用 37 CFR 1.84。
> 条文依据以 USPTO 官方文本（eCFR / MPEP）为准，本文为工程实现摘要。

## 一、37 CFR 1.84（Drawings）要点

| 要点 | 规则要点 | 本模块消费点 |
|---|---|---|
| 图号标注 | 视图按 "FIG. 1, FIG. 2, ..." 连续编号（大写 FIG. + 阿拉伯数字） | 渲染器 `figureCaption`（us 分支）；校验器 **V1**（编号连续） |
| 附图标记 | 使用阿拉伯数字；同一标记始终表示同一部分；标记不得带小数点 | 校验器 **V4**（一标记一组件）与渲染器 `data-ref` |
| 标记与说明书对应 | 图中出现的每个参考字符应在说明书具体描述部分中描述（MPEP 608.02） | 校验器 **V2**（图→文 fail）/ **V3**（文→图 warn，保守） |
| 图中文字 | 除必要（不可缺）的词语外不应使用文字 | 校验器 **V5**（疑似注释性长文 warn） |
| 线条与复印质量 | 不可褪变的黑色墨水、线条均匀清晰足够深；复印/扫描后仍可辨 | 渲染器构造期不变式（仅 `#000000`/`#FFFFFF`）；校验器 **V7**（画幅代理检查） |
| 幅面与边距 | 纸张 A4（21×29.7cm）或 letter（21.6×27.9cm）；边距 上/左 2.5cm、右/下 1.5cm（以 eCFR 现行文本为准） | A4 HTML 版式（`renderFiguresHtml`，打印边距按辖区调整时以此为准） |
| 黑白限制 | 附图一般应为黑白线条图，彩色仅限例外（需请求并缴费） | 渲染器不变式（两辖区一致） |

## 二、与 CNIPA 模式的规则差异

| 规则 | CNIPA | USPTO |
|---|---|---|
| V8 摘要附图 | 适用（多图应指定一幅） | **跳过**（无摘要附图制度） |
| V9 实用新型必须有附图 | 适用 | **跳过**（无实用新型制度） |
| 图号标注 | "图1" | "FIG. 1" |
| 附图说明措辞 | 中文模板（细则第 20 条第(四)项） | 英文 "FIG. N is a ... according to an embodiment." |
| 法条引用 | 细则第 20/21 条、审查指南 | 37 CFR 1.84、MPEP 608.02 |

## 三、工程边界

- 本模式覆盖示意图类附图（流程图/框图）的生成与核验；外观设计（design patent，37 CFR 1.152）
  图片类附图不适用，与 CNIPA 模式同一边界。
- eCFR 条文细节（如边距具体数值、彩色附图请求程序 1.84(a)(iv)）以 eCFR 现行文本为准；
  正式提交前由美国专利律师/代理人复核。
