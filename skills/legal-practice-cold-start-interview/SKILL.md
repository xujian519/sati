# 中国律师业务画像初始化

读取目标工作区已给的规则，仅询问尚缺且会影响方法的事项：服务对象、团队角色、主要地区与事项、利益冲突检查人、可用法源、对外数据边界、报价审批、客户交付格式及复核责任。

输出“已确认｜待确认｜来源规则”的画像草稿；用户未要求写入时只在对话展示。不得索取密钥、记录真实客户秘密或把个人执业画像写入公共模式。画像不替代每案利益冲突、时效、收费合规和法源核验。
