# 创造性三步法（专利法 A22.3）

## 待评估权利要求（独立权利要求 1）

一种枯草芽孢杆菌菌株，其特征在于：相对于出发菌株，其 srfA 操纵子的启动子区具有 -12 位 A→G 突变，在相同培养条件下表面活性素产量不低于出发菌株的 3 倍。

## 检索到的现有技术

- D1（最接近现有技术）：公开了所述出发菌株及其表面活性素生产能力。
- D2：公开了通过随机诱变结合表面活性素产量筛选获得高产菌株的常规方法，未涉及 srfA 启动子的定点改造。
- D3：公开了枯草芽孢杆菌启动子 -12 位序列影响转录强度的一般规律，未涉及 srfA 操纵子或表面活性素产量。

## 实验数据（申请文件记载）

权利要求 1 的菌株表面活性素产量为出发菌株的 3.2 倍；D2 方法获得的诱变株最高为 1.4 倍；转录分析显示 srfA 启动子活性提高约 2.8 倍。
