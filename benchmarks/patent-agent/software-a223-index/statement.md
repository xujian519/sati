# 创造性三步法（专利法 A22.3）

## 待评估权利要求（独立权利要求 1）

一种键值存储索引方法，其特征在于：采用 LSM 树组织数据；对 L0 与 L1 层执行全量合并，对 L2 及以上层执行分层合并；为每一层维护布隆过滤器；根据键的访问频次将热数据与冷数据分层存放。

## 检索到的现有技术

- D1（最接近现有技术）：公开了基于 LSM 树的键值存储，采用分层合并策略控制读放大。
- D2：公开了在 LSM 树的每个 SSTable 上维护布隆过滤器以减少无效读。
- D3：公开了存储系统中按访问频次进行热/冷数据分层，以降低读延迟。

## 任务

按三步法评估权利要求 1 的创造性（A22.3），说明三项已知手段的组合是否有技术启示，给出结论与置信度，法条精确到条款号。
