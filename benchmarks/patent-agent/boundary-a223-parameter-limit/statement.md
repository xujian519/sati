# 创造性：参数选择与临界效果（专利法 A22.3）

## 待评估权利要求（独立权利要求 1）

一种锂离子电池负极浆料，其特征在于：固含量为 68%-72%，粘度为 3000-5000 mPa·s，由所述浆料制成的负极片的压实密度为 1.65-1.75 g/cm³。

## 检索到的现有技术

- D1（最接近现有技术）：公开了锂离子电池负极浆料，固含量 55%-65%，粘度 1500-2800 mPa·s，负极片压实密度 1.50-1.60 g/cm³，未记载各参数的组合效果。
- D2：公开了负极片压实密度过高会导致颗粒破碎与循环性能下降，建议压实密度不超过 1.62 g/cm³。

## 实验数据（申请文件记载）

权利要求 1 范围内的实施例：1000 次循环容量保持率 92%-94%，极片无颗粒破碎。
范围外对比例：固含量 66% 或 74%、或压实密度 1.62 或 1.78 g/cm³ 时，容量保持率 76%-81%，且出现颗粒破碎或涂布缺陷。
