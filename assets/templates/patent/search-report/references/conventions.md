# 专利检索报告 — 版式惯例（Conventions）

> 生成或修改本模板前必读。与 `checklist.md` 配套。

## 1. 文书结构（固定顺序）

1. 页眉（所名 + 密级）
2. 文书抬头（类型徽标 / 标题 / 报告编号）
3. 案件信息表（委托方 / 发明名称 / 案卷号 / 检索人 / 检索日期 / 数据库范围）
4. 一、检索任务说明
5. 二、检索策略（关键词/分类号 + 检索式执行记录）
6. 三、技术方案 / 权利要求特征分解
7. 四、对比文件清单（按相关度 X → Y → A 排序）
8. 五、特征—文件映射矩阵
9. 六、初步结论
10. 七、引用日志
11. 八、假设与局限
12. 落款（检索人 / 审核人）+ 免责声明 + 页脚

## 2. 相关度代码

| 代码 | 含义 | 说明 |
|---|---|---|
| X | 高相关 | 可单独破坏新颖性或创造性 |
| Y | 可结合 | 需与其他 Y 或 X 文件结合 |
| A | 背景技术 | 非最接近现有技术，仅作背景 |
| P | 中间文件 | 申请日与最早优先权日之间的公开 |
| E | 冲突申请/同族 | 同一申请人的较早申请或同族 |

## 3. 检索式记录规范

- 每轮记录：数据库、完整检索式、命中数、日期。
- 检索式保留原始布尔逻辑，不得只写「关键词组合」而不给出字段与运算符。
- 命中数写阿拉伯数字；如命中过多未逐篇浏览，应说明筛选规则。

## 4. 特征-文件映射矩阵

- 行：本申请特征编号（F1/F2/…）。
- 列：对比文件编号（D1/D2/…）。
- 单元格：公开 / 未公开 / 部分公开 + pin-cite（`¶0023`）。
- 禁止空单元格：不相关写「—」。

## 5. 视觉与版式纪律

- 沿用 `assets/templates/patent/tokens.css` 品牌变量；agent 不改样式。
- 表格数字列使用 `tabular-nums`。
- 公开号、段号用等宽字体。
- 无证据支撑的检索结论降级为「模型推断」或「假设」。

## 6. 品牌契约注入点

同 `assets/templates/patent/DOCS.md` 与 `tokens.css`。抬头所名、密级、免责声明由 CSS 变量注入。
