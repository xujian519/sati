# 专利检索报告 — 引用日志规范

> 与 `patentability-opinion` 模板共享同一四字段引用纪律，本节为其在检索报告场景下的具体化。

## 四字段

每条关键断言必须包含：

1. **断言 / 结论**：例如「D1 公开 F1」、「R2 命中 86 篇」。
2. **来源类型**：现有技术文献 / 数据库记录 / 客户提供 / 模型推断 / 假设。
3. **来源名称**：公开号、数据库名、检索报告编号等。
4. **定位（pin-cite）**：段号 `¶XXXX`、检索式编号 `R1`、数据库结果页码。

## 常见来源类型与徽标

| 来源类型 | 徽标 | 示例 |
|---|---|---|
| 现有技术文献 | `badge-evidence` 证据支撑 | D1 ¶0015 |
| 数据库记录 | `badge-evidence` 证据支撑 | CNIPA 公布公告，命中数 86 |
| 客户提供 | `badge-client` 客户提供 | 技术交底书 HX-2026-0715 |
| 模型推断 | `badge-model` 模型推断 | 未穷尽检索的边界判断 |
| 假设 | `badge-assumption` 假设 | 待补充外文检索 |

## 规则

- 公开号、段号必须真实存在；禁止凭记忆编造。
- 检索式命中数不写「若干」「大量」等模糊词。
- 无法溯源的边界判断降级为「模型推断」或「假设」。
