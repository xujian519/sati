# 专利检索报告 — 自查清单（Checklist）

> 输出 `<artifact>` / 定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 文书结构完整且顺序正确
- [ ] 案件信息表填满（委托方、发明名称、案卷号、检索人、日期、数据库范围）
- [ ] 检索策略包含至少一轮数据库 + 完整检索式 + 命中数 + 日期
- [ ] 技术方案特征分解表与后续映射矩阵一致
- [ ] 对比文件清单按 X → Y → A 排序，相关度代码规范
- [ ] 特征-文件映射矩阵无空单元格，pin-cite 格式为 `¶XXXX`
- [ ] 初步结论覆盖新颖性/创造性，结论与置信度匹配
- [ ] 每条关键断言在引用日志中有对应行
- [ ] 无编造公开号、日期、段号；无法验证的内容标注为假设
- [ ] 免责声明与密级完整，品牌变量已注入
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 关键词/分类号覆盖技术方案的多个独立技术点
- [ ] 检索式体现布尔逻辑与字段限制
- [ ] 表格数字列使用 tabular 数字
- [ ] 引用日志与正文断言一致

## P2 — 锦上添花

- [ ] 同时产出 `.md` 源稿与 `.pdf`
- [ ] 导出 PDF 后抽查跨页表格是否断裂
