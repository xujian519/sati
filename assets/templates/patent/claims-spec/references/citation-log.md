# 权利要求书与说明书 — 引用与来源规范

> 权利要求书与说明书本身为专利申请文件，不强制要求引用日志。本节用于记录撰写过程中参考的现有技术、交底书来源与模型推断项，便于内部审稿。

## 来源类型

| 来源类型 | 用途 | 徽标 |
|---|---|---|
| 客户提供 | 技术交底书、附图、实验数据 | `badge-client` 客户提供 |
| 现有技术文献 | 背景技术引用、权利要求避让依据 | `badge-evidence` 证据支撑 |
| 模型推断 | 术语选择、权利要求布局建议 | `badge-model` 模型推断 |
| 假设 | 待补充的实施例或实验数据 | `badge-assumption` 假设 |

## 规则

- 背景技术中引用的现有技术必须给出公开号或来源。
- 权利要求中使用的术语需与说明书一致。
- 有益效果宣称需有实施例或实验数据支持；无法提供的标注为假设。
- 正式提交前删除所有内部来源标注。
