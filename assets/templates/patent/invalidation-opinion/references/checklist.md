# 专利无效宣告意见 / 无效请求书 — 自查清单（Checklist）

> 输出 `<artifact>` / 定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 文书结构完整且顺序正确
- [ ] 案件信息表填满（涉案专利号、专利名称、授权公告日、专利权人、请求人/委托方、分析日期）
- [ ] 总体立场明确，列出全部无效理由
- [ ] 涉案专利权利要求特征分解表覆盖全部独立权利要求
- [ ] 证据清单中每份对比文件公开号、公开日、来源、用途完整
- [ ] 对比文件公开日早于涉案专利优先权日/申请日；中间文件/冲突申请单独标注
- [ ] 每个无效理由按「事实认定 → 证据分析 → 法条适用 → 结论」四段式组织
- [ ] 法条引用精确到条款号
- [ ] 逐权利要求结论表覆盖全部目标权利要求
- [ ] 每条关键断言在引用日志中有对应行
- [ ] 无编造公开号、日期、段号
- [ ] 免责声明与密级完整，品牌变量已注入
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 无效理由之间不重复、不矛盾
- [ ] 从属权利要求引用关系在结论表中说明
- [ ] 证据分析与法条结论一一对应
- [ ] 表格数字列使用 tabular 数字
- [ ] 引用日志与正文断言一致

## P2 — 锦上添花

- [ ] 同时产出 `.md` 源稿与 `.pdf`
- [ ] 导出 PDF 后抽查表格是否跨页断裂
