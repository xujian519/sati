# 专利无效宣告意见 / 无效请求书 — 引用日志规范

> 与 `patentability-opinion` 模板共享同一四字段引用纪律。

## 四字段

每条关键断言必须包含：

1. **断言 / 结论**：例如「D1 公开 F1」、「权利要求 4 不清楚」。
2. **来源类型**：现有技术文献 / 法条 / 审查指南 / 客户提供 / 模型推断 / 假设。
3. **来源名称**：公开号、法条、审查指南章节、无效检索报告编号。
4. **定位（pin-cite）**：段号 `¶XXXX`、法条条款、指南章节。

## 常见来源类型与徽标

| 来源类型 | 徽标 | 示例 |
|---|---|---|
| 现有技术文献 | `badge-evidence` 证据支撑 | D1 ¶0015 |
| 法条 | `badge-evidence` 证据支撑 | 《专利法》第22条第3款 |
| 审查指南 | `badge-evidence` 证据支撑 | 审查指南第二部分第四章 |
| 客户提供 | `badge-client` 客户提供 | 涉案专利授权公告文本 |
| 模型推断 | `badge-model` 模型推断 | 技术启示判断 |
| 假设 | `badge-assumption` 假设 | 待补充外文对比文件 |

## 规则

- 法条必须精确到条款号，指南精确到部分/章/节。
- 对比文件公开号、公开日、段号必须真实存在。
- 无法溯源的无效主张降级为「模型推断」或「假设」。
- 从属权利要求结论应引用其引用的独立权利要求结论。
