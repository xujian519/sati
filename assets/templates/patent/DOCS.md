# Sati 专利文书品牌契约

> 类别：Legal Document / Patent
> 适用：专利代理事务所、专利律师出具的正式书面交付物（意见书、检索报告、OA 答复、权利要求书、无效意见等）。

## 1. 品牌定位与气质

Sati 专利文书的视觉身份是**「可信赖的专业文件」**：克制、清晰、耐审读。它不应像营销材料那样追求视觉冲击，而应让审查员、客户、法官在第一眼就能识别出这是一份经过专业处理的法律技术文件。

核心原则：

- **证据优先**：版式服务于信息密度与可追溯性，而非装饰。
- **层级明确**：标题、正文、表格、元数据、脚注的阅读顺序一眼可辨。
- **克制用色**：主色仅用于标题与表头；语义色仅用于结论/风险徽章。
- **A4 打印优先**：电子阅读与纸质打印体验一致，边距、字号、分页均按 A4 优化。
- **可品牌化**：所有视觉常量通过 CSS 变量（`--sati-doc-*`）暴露，不同事务所可覆盖，agent 不硬编码样式。

## 2. 色彩系统

### 主色与中性色

| 角色 | 变量 | 默认值 | 用途 |
|------|------|--------|------|
| 主色 | `--sati-doc-accent` | `#1f3a5f` | 标题、表头文字、抬头下划线、文档类型框 |
| 深主色 | `--sati-doc-accent-strong` | `#16324f` | H1/H2 标题、强调文字 |
| 正文 | `--sati-doc-body` | `#1a1a1a` | 正文、表格内容 |
| 次要文字 | `--sati-doc-muted` | `#6b6b6b` | 页眉、页脚、说明文字、日期 |
| 边框 | `--sati-doc-border` | `#c9c9c9` | 表格、元数据框、分隔线 |
| 表头背景 | `--sati-doc-header-bg` | `#f6f6f2` | 表头、定义列表标签、免责声明背景 |
| 页面背景 | `--sati-doc-surface` | `#ffffff` | 页面底色 |

默认主色 `#1f3a5f` 为**藏蓝**（navy），传递稳重、正式、可信赖的律所气质。不同事务所可替换为自身 VI 主色，但应保持深色、低饱和，避免鲜艳色彩。

### 语义色（风险/结论徽章）

| 角色 | 变量 | 默认值 | 用途 |
|------|------|--------|------|
| 高风险 / 不具备 / 驳回 | `--sati-doc-danger` | `#b42318` | 创造性存疑、客体驳回、新颖性不具备 |
| 中风险 / 存疑 / 待补 | `--sati-doc-warning` | `#b54708` | 需补充检索、需修改权利要求 |
| 低风险 / 具备 / 通过 | `--sati-doc-success` | `#067647` | 具备新颖性、具备创造性、客体合格 |
| 证据型 | `--sati-doc-evidence` | `#1f3a5f` | 证据支撑的断言 |
| 客户来源 | `--sati-doc-client` | `#6b6b6b` | 客户提供的事实 |
| 模型推断 | `--sati-doc-model` | `#8a8a8a` | 无直接证据的推理 |
| 假设 | `--sati-doc-assumption` | `#6b6b6b` | 明确假设项 |

语义色必须对应真实法律含义，不可用于装饰。agent 渲染时应严格按证据状态选择徽章，禁止为「好看」而调整。

## 3. 字体系统

### 字体族

| 角色 | 变量 | 默认值 | 用途 |
|------|------|--------|------|
| 正文/标题 | `--sati-doc-font-serif` | 宋体/思源宋体回退 | 正文、大标题，营造正式文书感 |
| UI/表头 | `--sati-doc-font-sans` | 黑体/思源黑体回退 | 表头、页眉、页脚、徽章、元数据 |
| 等宽 | `--sati-doc-font-mono` | SF Mono / Consolas | 公开号、段号、案卷号 |

中文场景优先衬线体正文，衬线体在长篇法律文本中更易审读；黑体用于信息密度高的表头与元数据，形成对比。

### 字号层级（A4，12pt 基准）

| 元素 | 大小 | 字重 | 字体 | 说明 |
|------|------|------|------|------|
| 文档类型标签 | 9pt | 400 | sans | 居中，加框，字间距 0.4em |
| H1 标题 | 16pt | 700 | sans | 居中，深主色，字间距 0.12em |
| H2 章节 | 13pt | 700 | sans | 下划线分隔 |
| H3 小节 | 11.5pt | 600 | sans | 主色 |
| 正文 | 12pt | 400 | serif | 行高 1.7 |
| 表格 | 10.5pt | 400 | serif | 表头 600 sans |
| 页眉/页脚 | 8.5–9.5pt | 400 | sans | 次要色 |
| 徽章 | 9pt | 400 | sans | 内联标签 |
| pin-cite | 9.5pt | 400 | mono | 段号定位 |

## 4. 版式与网格

### 页面尺寸

- 纸张：A4（210mm × 297mm）
- 打印边距：`16mm 18mm 18mm 18mm`（上/右/下/左）
- 屏幕阅读最大宽度：`174mm`
- 屏幕内边距：`0 18mm`

变量：`--sati-doc-page-margin`、`--sati-doc-body-padding`、`--sati-doc-body-max-width`。

### 文档骨架（所有专利文书通用）

1. **抬头**：事务所名（左）+ 密级/状态（右）
2. **文号区**：文档类型标签 + 主标题 + 文档编号/版本
3. **元数据**：委托方、发明名称、案卷号、分析依据、日期等（定义列表或表格）
4. **正文章节**：固定顺序，见各模板 SKILL.md
5. **证据与引用日志**：每份结论必须可溯源
6. **落款与免责声明**：签名区、免责声明、页脚

### 间距

- 章节间距：5–6mm
- H2 上下：6mm / 3mm
- 表格边距：2.5mm 上下
- 引用块/免责声明：3–4mm 内边距
- 签名区顶部：8mm

## 5. 组件规范

### 表格

- 全宽、`border-collapse: collapse`
- 表头背景：`--sati-doc-header-bg`
- 表头文字：`--sati-doc-accent-strong`、sans、600
- 单元格边框：`1px solid var(--sati-doc-border)`
- 斑马行：`tbody tr:nth-child(even) { background: #fbfbf9 }`
- 数字列右对齐（`tabular-nums`）
- 表头打印重复：`thead { display: table-header-group }`

### 徽章（Badge）

徽章用于标识**置信度或结论**，不是装饰：

- `badge-risk-high`：填充背景，白字
- `badge-risk-mid`：填充背景，白字
- `badge-risk-low`：填充背景，白字
- `badge-evidence`：主色边框，主色文字
- `badge-client`：次要色边框，次要色文字
- `badge-model`：虚线灰边框，灰文字
- `badge-assumption`：虚线次要色边框，斜体

### 引用日志（Citation Log）

每条关键断言占一行：

- 断言/结论
- 来源类型（现有技术文献 / 法条 / 客户提供 / 模型推断 / 假设）
- 来源名称（公开号 / 法条 / 文件名）
- 日期
- 置信度徽章
- 定位 pin-cite（段号 / 章节）

无证据支撑的断言必须降级为「模型推断」或「假设」。

### 免责声明

默认文案（可在品牌契约中按事务所合规要求覆盖）：

> 本分析由 AI 辅助生成，不构成正式法律意见。专利申请和专利性判断应由具备资质的专利代理人或专利律师确认。本文件含商业秘密与保密信息，仅限指定接收人使用；未经书面许可不得转发或复制。

## 6. 打印与导出

### PDF 导出

使用 Playwright / Chromium 打印到 PDF：

```js
await page.pdf({
  path: 'output.pdf',
  format: 'A4',
  printBackground: true,
  margin: { top: '16mm', right: '18mm', bottom: '18mm', left: '18mm' }
});
```

### 页码

单文件 HTML 不内置页码；PDF 导出时由打印引擎注入。如需显式页码，在导出脚本中通过 `@page { @bottom-center { content: counter(page) } }` 注入。

### 分页控制

- `h2 { page-break-after: avoid }`
- `tr { page-break-inside: avoid }`
- 表格跨页时表头重复：`thead { display: table-header-group }`

## 7. 变量覆盖与品牌注入

### 默认变量表

见同目录 `tokens.css`。所有专利文书模板引用 `--sati-doc-*` 变量，再回退到自身语义变量。

### 按产品覆盖

事务所/白标产品可在 `products/<标识>/brand/theme.json` 或 `config/sati.yaml` 中声明覆盖值。渲染管线生成 HTML 时，把覆盖后的值写入 `<style>` 块或替换 `:root` 变量。

### Agent 行为约束

- agent 不得直接修改 `assets/templates/patent/tokens.css`。
- agent 填充内容时只能修改 HTML 的文本与结构，不得改写样式。
- 如需调整品牌，应在 `products/` 下新建白标配置，并通过渲染管线注入。

## 8. 可访问与一致性

- 正文与背景对比度 ≥ 7:1。
- 语义色（成功/警告/危险）不依赖颜色作为唯一信息通道：徽章同时带文字说明。
- 中文行高 ≥ 1.7，避免拥挤。
