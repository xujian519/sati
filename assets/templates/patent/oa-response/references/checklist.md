# 审查意见答复 / 意见陈述书 — 自查清单（Checklist）

> 输出 `<artifact>` / 定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 文书结构完整且顺序正确
- [ ] 案件信息表填满（申请号、发明名称、通知书编号、发文日、答复日期、申请人/代理人）
- [ ] 总体立场明确，列出全部答复要点
- [ ] 权利要求修改对照表包含修改前/修改后/修改依据三列
- [ ] 修改后的独立权利要求全文呈现，新增部分用下划线加粗标注
- [ ] 每条争辩意见按「审查意见要点 → 答复要点 → 事实/证据 → 法条 → 结论」五段式组织
- [ ] 法条引用精确到条款号，无"相关规定"式模糊表述
- [ ] 证据清单包含审查员引用的全部对比文件
- [ ] 每条关键断言在引用日志中有对应行
- [ ] 无编造公开号、日期、段号
- [ ] 免责声明与密级完整，品牌变量已注入
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 争辩意见逐条对应通知书中的审查意见，无遗漏
- [ ] 事实与证据分析包含逐字摘录 + pin-cite
- [ ] 修改依据与争辩意见中的技术问题一致
- [ ] 表格数字列使用 tabular 数字
- [ ] 引用日志与正文断言一致

## P2 — 锦上添花

- [ ] 同时产出 `.md` 源稿与 `.pdf`
- [ ] 导出 PDF 后抽查权利要求区块是否跨页断裂
