# 审查意见答复 / 意见陈述书 — 版式惯例（Conventions）

> 生成或修改本模板前必读。与 `checklist.md` 配套。

## 1. 文书结构（固定顺序）

1. 页眉（所名 + 密级）
2. 文书抬头（类型徽标 / 标题 / 答复编号）
3. 案件信息表（申请号 / 发明名称 / 通知书编号 / 发文日 / 答复日期 / 申请人或代理人）
4. 一、总体立场
5. 二、权利要求修改说明（修改对照表 + 修改后权利要求全文）
6. 三、争辩意见（逐条审查意见：要点 → 答复 → 事实/证据 → 法条 → 结论）
7. 四、证据清单
8. 五、引用日志
9. 六、结论与请求
10. 落款 + 免责声明 + 页脚

## 2. 争辩意见五段式

每条争辩意见按以下结构组织：

1. **审查意见要点**：准确转述审查员观点，不歪曲。
2. **答复要点**：明确提出我方反对/接受/限缩立场。
3. **事实与证据分析**：引用 D1/D2/公知常识证据，逐字摘录 + pin-cite。
4. **法条适用与结论**：引用《专利法》具体条款与《专利审查指南》章节。

## 3. 权利要求修改标注

- 新增内容用下划线 + 加粗（`<span class="added">`）。
- 删除内容仅在修改对照表中用删除线（`<span class="deleted">`），正式权利要求文本中不保留删除线。
- 修改后的独立权利要求必须全文呈现，不能只写「参见修改对照表」。

## 4. 法条引用

- 新颖性：《专利法》第22条第2款。
- 创造性：《专利法》第22条第3款 + 《专利审查指南》第二部分第四章。
- 客体/单一性/修改超范围：引用对应具体条款，禁止模糊表述。

## 5. 视觉与版式纪律

- 沿用 `assets/templates/patent/tokens.css` 品牌变量；agent 不改样式。
- `claim-text` 区块用于权利要求全文，左侧 accent 竖线标识。
- 表格数字列使用 `tabular-nums`。
- 无证据支撑的法条适用结论降级为「模型推断」或「假设」。

## 6. 品牌契约注入点

同 `assets/templates/patent/DOCS.md` 与 `tokens.css`。抬头所名、密级、免责声明由 CSS 变量注入。
