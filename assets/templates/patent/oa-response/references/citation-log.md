# 审查意见答复 / 意见陈述书 — 引用日志规范

> 与 `patentability-opinion` 模板共享同一四字段引用纪律。

## 四字段

每条关键断言必须包含：

1. **断言 / 结论**：例如「D1 未公开加热单元」、「自动启停非公知常识」。
2. **来源类型**：现有技术文献 / 法条 / 审查意见通知书 / 客户提供 / 模型推断 / 假设。
3. **来源名称**：公开号、通知书编号、法条、检索报告编号等。
4. **定位（pin-cite）**：段号 `¶XXXX`、法条条款、通知书第 X 页第 X 段。

## 常见来源类型与徽标

| 来源类型 | 徽标 | 示例 |
|---|---|---|
| 现有技术文献 | `badge-evidence` 证据支撑 | D1 ¶0015 |
| 法条 | `badge-evidence` 证据支撑 | 《专利法》第22条第3款 |
| 审查意见通知书 | `badge-client` 客户提供 | 通知书 CN...20260805OA001 第2页 |
| 客户提供 | `badge-client` 客户提供 | 修改后的权利要求书 |
| 模型推断 | `badge-model` 模型推断 | 非公知常识论证 |
| 假设 | `badge-assumption` 假设 | 待补充公知常识证据 |

## 规则

- 法条必须精确到条款号。
- 审查意见通知书引用必须精确到通知书编号 + 页码/段落。
- 公开号、段号必须真实存在；禁止凭记忆编造。
- 无法溯源的争辩前提降级为「模型推断」或「假设」。
