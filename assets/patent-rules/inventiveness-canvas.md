## 📐 一、法律框架：创造性是什么

```
┌─────────────────────────────────────────────────────────┐
│                    专利法 第22条第3款                      │
│                                                         │
│  创造性，是指同申请日以前已有的技术相比，                        │
│                                                         │
│  ┌──────────────────────────────────────────────────┐   │
│  │ 发明   → 有突出的实质性特点 + 显著的进步           │   │
│  └──────────────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────────────┐   │
│  │ 实用新型 → 有实质性特点 + 进步                    │   │
│  └──────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘

核心逻辑：要求保护的发明相对于现有技术是否"显而易见"
         · 显而易见 → 不具有突出的实质性特点 → 不具备创造性
         · 非显而易见 → 具有突出的实质性特点 + 有显著的进步 → 具备创造性
```

### 与新颖性的关键区别

| 维度 | 新颖性 (A22.2) | 创造性 (A22.3) |
|------|--------------|-------------|
| 比较方法 | **单独对比** — 一篇对比文件逐一比对 | **组合对比** — 多篇对比文件可结合 |
| 对比文件范围 | 含申请日前他人申请、申请日后公开的专利文件 | **不含**抵触申请 |
| 判断对象 | 技术方案是否被"明确公开"或"隐含公开" | 技术方案是否"显而易见" |
| 标准门槛 | "有/无"的二元判断 | "高/低"的程度判断 |

## 🧩 二、核心方法：三步法（Three-Step Method）

> 《专利审查指南》第二部分第四章 §3.2.1.1

```
┌─────────────────────────────────────────────────────────────────┐
│                        ★ 三 步 法 ★                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  STEP 1              STEP 2              STEP 3                 │
│  ┌──────────┐       ┌──────────┐       ┌──────────┐            │
│  │ 确定     │       │ 确定     │       │ 判断     │            │
│  │ 最接近的 │  ──→  │ 区别特征 │  ──→  │ 是否     │  ──→ 结论  │
│  │ 现有技术 │       │ 和实际解 │       │ 存在     │            │
│  │          │       │ 决的问题 │       │ 技术启示 │            │
│  └──────────┘       └──────────┘       └──────────┘            │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 关键点： 所属技术领域的技术人员 · 申请日前的现有技术    │   │
│  │         避免"事后诸葛亮" · 整体考虑技术方案             │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

### ✅ Step 1：确定最接近的现有技术

**选择优先级**（2023年指南修改强化）：

| 优先级 | 考虑因素 |
|------|--------|
| 🔴 **最高优先** | 与发明要解决的技术问题**相关联**的现有技术（2023新增强调） |
| 🟠 次优先 | 技术领域相同/相近 |
| 🟡 再次 | 技术效果或用途最接近 |
| 🟢 补充 | 公开了发明的技术特征最多 |

> ⚠️ **2023修改要点**：不得片面强调本申请与现有技术"共有技术特征的多少"，而忽视发明所要解决的技术问题与现有技术所针对的问题之间的关系。

### ✅ Step 2：确定区别技术特征和发明实际解决的技术问题

**操作流程**：

```
权利要求的技术方案  →  逐特征比对最接近现有技术  →  找出区别特征
                                                          ↓
                                            基于区别特征在发明中达到的技术效果
                                                          ↓
                                            重新确定"发明实际解决的技术问题"
```

**关键规则**（2023年指南修改强化）：

| 规则 | 内容 |
|------|------|
| **匹配原则** | 重新确定的技术问题必须与区别特征在发明中所能达到的**技术效果相匹配** |
| **禁止循环** | 技术问题不得是区别特征本身，也不得包含对区别特征的指引或暗示 |
| **特殊情形**（新增） | 当所有技术效果与最接近现有技术相当时，可重新确定技术问题为：**"提供一种不同于最接近现有技术的可供选择的技术方案"** |
| **整体考虑** | 对功能上相互支持、存在相互作用关系的技术特征，应整体考虑这些特征及其关系所达到的技术效果 |

### ✅ Step 3：判断要求保护的发明对本领域技术人员是否显而易见

**存在技术启示的三种法定情形**：

```
┌──────────────────────────────────────────────────────────────┐
│         审查指南列举的存在技术启示的三种情况                   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ① 区别特征为公知常识                                        │
│     └─ 本领域解决该技术问题的惯用手段                          │
│     └─ 教科书/技术词典/技术手册中披露的手段（2023扩展）        │
│     └─ 须说明"为什么该技术手段在**该技术领域**解决             │
│        **该具体技术问题**是公知的"（2023新增）                │
│                                                              │
│  ② 区别特征为最接近对比文件其他部分披露的技术手段             │
│     └─ 在该其他部分所起的作用 与 在发明中所起的作用 **相同**   │
│                                                              │
│  ③ 区别特征为另一篇对比文件中披露的相关技术手段               │
│     └─ 该技术手段在该对比文件中所起的作用 与                   │
│       在发明中所起的作用 **相同**                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**不存在技术启示的抗辩方向**：

| 抗辩理由 | 法律含义 |
|---------|--------|
| 无改进动机 | 最接近现有技术不存在改进需求，本领域技术人员不会想到去改进 |
| 技术领域不同 | 另一篇对比文件属于不同技术领域，无交叉动机 |
| 作用不同 | 区别特征在对比文件中的作用与其在发明中的作用不同 |
| **存在技术障碍** | 现有技术存在相反的教导，阻止本领域技术人员进行该改进 |
| 无合理成功预期 | 基于现有技术，不能合理预期改进会成功 |

## 📊 三、审查基准体系

```
                         创造性审查基准
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
   突出的实质性特点         显著的进步            辅助判断因素
   （非显而易见性）      （有益技术效果）     （指引性/参考性）
        │                     │                     │
        │                     │               ┌─────┴─────┐
   ┌────┴────┐           ┌────┴────┐        │ · 开拓性发明
   │ 三步法   │           │ 产生了   │        │ · 长期未解决难题
   │          │           │ 有益技术 │        │ · 克服技术偏见
   │ □Step1  │           │ 效果     │        │ · 预料不到效果
   │ □Step2  │           └──────────┘        │ · 商业成功
   │ □Step3  │                                └─────────────┘
   └─────────┘
```

### 辅助判断因素详解

| 因素 | 标准 | 示例 |
|------|------|------|
| **开拓性发明** | 全新的、技术历史上从未有过的技术解决方案 | 白炽灯、收音机、雷达、激光器 |
| **长期未解决难题** | 长期渴望解决但一直未能成功 | 农场牲畜无痛永久标记（冷冻烙印替代热烙） |
| **克服技术偏见** | 克服了本领域技术人员普遍存在的成见 | 取消热灌装后立即隔离空气的工艺（原被认为必须） |
| **预料不到的技术效果** | 产生"质"的变化（新性能）或"量"的变化（超出预期） | 癌细胞活性抑制率提高约40倍（经典电子等排体替换） |
| **商业成功** | 发明取得商业成功，且源于技术特征而非营销 |

> ⚠️ **辅助判断因素的使用限制**：辅助因素为"指引性"而非"替代性"——不能替代三步法的分析，只能在三步法结论临界时提供参考佐证。

```
┌─────────────────────────────────────────────────────────────────┐
│                 2025年《专利审查指南》修改                         │
│                 第二部分第四章 §6.4                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │

│                                                                 │

│  │                                                         │   │

│  │   → 对创造性评价无贡献，不会使权利要求具备创造性            │   │
│  │                                                         │   │
│  │ → 若能证明某特征（如显示屏大小）影响快门控制速度             │   │

│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  实务影响：                                                        │
│  · "保护范围与技术贡献一致" — 堆砌无贡献特征不会带来创造性          │
│  · 区别技术特征的**数量**多少 ≠ 创造性判定的**实质**标准            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 📂 五、典型案例全景

### 5.1 最高法院知识产权法庭典型案例

#### 🏛️ 案例一：(2025)最高法知行终959号 — 磁悬浮永磁体案

```
┌─────────────────────────────────────────────────────────────────┐
│ │ 裁判要旨                                                        │
│ ├─────────────────────────────────────────────────────────────────┤
│ │                                                                 │
│ │  1. 【否定"原理相同"推定】                                        │
│ │     应避免仅凭"原理相同"即直接或简单"推定"专利技术方案              │
│ │     属于显而易见。即使基于同一自然规律或科学原理，二者的              │
│ │     具体实现方式仍可能存在实质性差异。                              │
│ │                                                                 │
│ │  2. 【"容易想到""易于获得"须证据支持】                             │
│ │     在没有公知常识性证据支持、未进行充分说明、且与在先                │
│ │     审查标准不一致的情况下，认定核心发明构思的区别特征               │
│ │     "容易想到""易于获得"，实难令人信服。                            │
│ │                                                                 │
│ │  3. 【三重审查维度】                                               │
│ │     → 所要解决的技术问题是否不同                                   │
│ │     → 采用的技术手段是否实质不同                                   │
│ │     → 实现的技术效果是否不同                                       │
│ │     若三者均有实质差异，不得因原理相同而否定创造性                    │
│ │                                                                 │
│ │  4. 【与在先审查标准的一致性】                                      │
│ │     当多份在先决定均认定相似方案具备创造性时，                                                                     │
│ │     对后续审查标准的适用应保持一致                                  │
│ │                                                                 │
│ └─────────────────────────────────────────────────────────────────┘
```

#### 🏛️ 案例二：(2025)最高法知行终1030号 — 苏金单抗案

> 核心争议：抗体轻链第97位半胱氨酸的选择性还原是否具备创造性

- 区别特征："苏金单抗抗体轻链第97位的半胱氨酸被选择性还原"
- 该特征**未被任何对比文件公开**，现有技术中的选择性还原方法不涉及苏金单抗
- 对比文件8虽有MAB007抗体还原，但未教导该方法和位点可**普遍适用于其他抗体**
- **结论**：无证据证明属于公知常识 → 具备创造性，维持有效

### 5.3 AI场景创新类专利：创造性判断的特殊规则

```
┌─────────────────────────────────────────────────────────────────┐
│ 案例9深度分析："用于处理图像的方法和装置" — AI场景创新的三步法实践     │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  技术方案：球场场景关键点检测 → "一个体一模型" + 输出可见性信息        │
│                                                                 │
│  三步法分析：                                                      │
│                                                                 │
│  STEP 1 → 对比文件1、2涉及人脸关键点定位（通用模型）                  │
│                                                                 │
│  STEP 2 → 区别特征：                                              │
│           · 不同目标对象对应不同模型（"一个体一模型"）                 │
│           · 输出可见性信息（判断关键点是否在拍摄图视野内）             │
│           实际解决的技术问题："如何确定同一目标对象在不同拍摄图中的     │
│                             对应关系"                              │
│                                                                 │
│  STEP 3 → 对比文件1、2的人脸模型是**通用模型**，不涉及同一人脸在多图     │
│           中的对应；对比文件2的"遮挡概率"≠本申请的"可见性信息"；         │
│           含义和作用均不同；**未给出结合启示** → 具备创造性            │
│                                                                 │
│  方法论贡献：                                                      │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  "整体考虑" 的双重含义                                    │   │
│  │                                                         │   │
│  │  ① 勿"机械割裂"：场景特征与算法特征之间存在功能支持关系     │   │
│  │     不能将场景特征与算法特征孤立对待                       │   │
│  │                                                         │   │
│  │  ② 勿"简单拼合"：不能因为特征之间存在一定关联              │   │
│  │     就把所有特征拼为一个整体从而轻易认定有创造性            │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  AI场景创新的判断标准：                                             │
│   若不同应用场景导致 算法/模型的结构、训练数据、输入输出、选择等        │
│   构成实质性区别 → 非显而易见 + 有相应技术效果 → 具备创造性             │
│                                                                 │
│  2025年指南新增示例：                                              │
│  ·【例18】场景不同但算法未做实质改变 → 不具备创造性                    │
│  ·【例19】场景相似但算法做了实质调整和改进 → 具备创造性                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

│       应慎重认定本领域技术人员具有改进动机                           │
│     → 前沿领域面临的不确定因素更多，改进动机的认定更应审慎              │
│                                                                 │

│                                                                 │
│  📌 "创造性判断中技术启示的认定"                                     │
│     → 应综合考虑区别特征在发明中的技术作用、                            │
│       现有技术整体教导、是否有相反的教导                              │
│                                                                 │
│  📌 "区别技术特征与其他特征的协调配合关系对改进动机的影响"              │
│     → 存在技术障碍时（如相反的结构约束），不应认定有技术启示            │

### 6.2 撰写阶段的实务要点

```
┌─────────────────────────────────────────────────────────────────┐
│ ★ 核心理念："保护范围与技术贡献一致"                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ✅ 应当做的：                                                    │
│                                                                 │
│  1. 说明书中清晰记载区别技术特征与发明解决的技术问题之间              │
│     的因果关联和实质贡献                                           │
│                                                                 │
│  2. 重点阐述区别特征如何通过新的技术手段或技术原理，                    │
│     克服了现有技术的缺点并带来了预期的技术效果                        │
│                                                                 │
│  3. 提供对比实验数据、测试报告、仿真结果等证据                        │
│                                                                 │
│  4. 权利要求聚焦核心技术贡献，避免堆砌无贡献特征                      │
│                                                                 │
│  ❌ 应当避免的：                                                    │
│                                                                 │
│  1. 将技术方案中的所有特征不加区分地列举                              │
│                                                                 │
│  2. 加入对技术问题解决无贡献的常规外观、公知常识或通用组件               │
│     → 这些特征在创造性评价时会被排除，反而不当限缩保护范围              │
│                                                                 │
│  3. 权利要求中堆砌或拼凑大量特征                                     │
│     → 区别技术特征的数量 ≠ 创造性的实质标准                          │
│                                                                 │
│  4. 草率主张预料不到的技术效果（除非有明显超出预期的效果差异）           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 6.3 答辩/无效阶段的策略要点

```
┌─────────────────────────────────────────────────────────────────┐
│ ★ 核心策略："围绕技术特征对解决技术问题的作用展开论证"                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  抗辩方向     │  论证要点                                          │
│ ─────────────┼─────────────────────────────────────────────────  │
│  无改进动机   │  最接近现有技术不存在改进需求                          │
│              │  本领域技术人员不会想到去改进                          │
│ ─────────────┼─────────────────────────────────────────────────  │
│  技术领域不同 │  对比文件属于不同技术领域，无交叉动机                    │
│ ─────────────┼─────────────────────────────────────────────────  │
│  作用不同     │  区别特征在对比文件中的作用 ≠ 其在发明中的作用            │
│ ─────────────┼─────────────────────────────────────────────────  │
│  存在技术障碍 │  现有技术存在相反的教导/结构约束                         │
│              │  阻止本领域技术人员进行该改进                           │
│ ─────────────┼─────────────────────────────────────────────────  │
│  预料不到效果 │  提供对比数据证明技术效果产生"质"或"量"的惊人变化         │
│ ─────────────┼─────────────────────────────────────────────────  │
│  克服技术偏见 │  证明本领域存在的普遍成见被本发明打破                     │
│ ─────────────┼─────────────────────────────────────────────────  │
│  长期未解决   │  证明该技术问题长期存在但无人成功解决                     │
│ ─────────────┼─────────────────────────────────────────────────  │
│  无贡献特征   │  若修改权利要求，新增特征必须对解决技术问题有实质贡献       │
│              │  后补证据须在合理期限内提交，且得到说明书支持              │
│ ─────────────┼─────────────────────────────────────────────────  │
│  针对"原理    │  即使基于同一原理，若技术问题+手段+效果三重不同            │
│    相同"      │  → 应以实质差异而非原理相同为准判断创造性              │
│ ─────────────┼─────────────────────────────────────────────────  │
│  针对"容易    │  要求对方提供公知常识性证据支持                           │
│    想到"      │  若仅有断言无证据 → 创造性应予以认定                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 📋 七、特殊类型发明的创造性判断

```
┌─────────────────────────────────────────────────────────────────┐
│ 类型          │  创造性判断要点                                    │
├──────────────┼─────────────────────────────────────────────────┤
│ 开拓性发明    │  天然具备创造性，但极为罕见                          │
├──────────────┼─────────────────────────────────────────────────┤
│ 组合发明      │  是否产生新的、超出各组分简单叠加的技术效果              │
│              │  → 是：具备创造性；否：显而易见                       │
├──────────────┼─────────────────────────────────────────────────┤
│ 选择发明      │  从已知范围中选出未具体披露的个别方案                    │
│              │  → 产生预料不到的技术效果 → 具备创造性               │
├──────────────┼─────────────────────────────────────────────────┤
│ 转用发明      │  将某一技术领域的现有技术转用到其他领域                  │
│              │  考虑：领域的远近、转用难易、是否克服技术困难             │
│              │  类似/相近领域 + 无预料不到效果 → 不具备               │
├──────────────┼─────────────────────────────────────────────────┤
│ 用途发明      │  已知产品的新用途                                     │
│              │  考虑：用途的新颖性、是否产生预料不到的效果              │
│              │  对于医疗器械：单纯用途区别不影响产品本身 → 不足          │
├──────────────┼─────────────────────────────────────────────────┤
│ 化合物发明    │  结构相似性 + 效果可比性双重判断                        │
│              │  经典电子等排体替换 + 约40倍活性提高 = 具备创造性       │
│              │  约2倍活性提高 + 无其他非显而易见证据 = 不具备          │
├──────────────┼─────────────────────────────────────────────────┤
│ 晶型发明      │  晶型本身可否预期 + 技术效果是否预料不到                  │
│              │  须有实验数据支持（2024年呋喹替尼晶型案参考）          │
├──────────────┼─────────────────────────────────────────────────┤
│ AI/算法发明   │  考虑：应用场景是否导致算法/模型的实质性调整              │
│              │  场景不同但算法未改变 → 通常不具备                       │
│              │  场景驱动算法的实质性改进 → 可能具备                     │
├──────────────┼─────────────────────────────────────────────────┤
│ 标准必要专利  │  标准演进中版本迭代的技术方案                             │
│              │  不同版本标准之间是否具有结合启示 → 独立判断              │
└──────────────┴─────────────────────────────────────────────────┘
```

## 🎯 八、总结：创造性判断的核心公式

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│                   创造性 = f ( 显而易见的程度 )                     │
│                                                                 │
│   非显而易见性 ↑                                                │
│   │                                                              │
│   │  ★ 开拓性发明                                                │
│   │                                                              │
│   │       ★ 长期未解决难题 + 克服技术偏见                          │
│   │                                                              │
│   │             ★ 预料不到的技术效果（质变/量变）                     │
│   │                                                              │
│   │                    ★ 三步法 → 有区别 + 无技术启示               │
│   │                                                              │
│   │                           ★ 三步法 → 有区别 + 有技术启示        │
│   │                                                              │
│   │                                  ★ 三步法 → 无实质区别         │
│   │                                                              │
│   └──────────────────────────────────────────→ 对技术效果的要求   │
│                                                                 │
│  当非显而易见性越低，对发明的技术效果要求越高                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
