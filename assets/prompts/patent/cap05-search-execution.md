# CAP05 检索执行（W-05 patent-search-executor）

## 目标

按 `search-plan.md` 执行检索，筛选高相关对比文件，写入案卷 outputs。

## 输入

- `outputs/search-plan.md`（必需）
- CAP02 报告（相关性评估时引用）

## 步骤

1. 按检索规划**分轮执行**（宽→窄），记录每轮检索式与命中数
2. 筛选 **Top N** 高相关文献（N 由意图决定，通常 3–15）
3. 每篇文献提取：公开号/专利号、标题、申请人、公开日、相关权利要求或说明书段落摘要
4. 评估与本案的**相关性**（高/中/低 + 理由）
5. 不足时：`webfetch` 或 bash 调用外部检索；仍不足则标注「检索未命中」

## 输出

1. `outputs/search-results.md` — 汇总表 + 分文献摘要
2. 可选：`outputs/检索-{代号}_{语言}_{主题}.md` — 单篇深度摘录

`search-results.md` 须含：

```markdown
# 检索结果

## 执行记录（轮次、检索式、命中数）
## 对比文件清单
| 序号 | 文献号 | 标题 | 公开日 | 相关性 | 摘要 |
## 推荐作为 D1/D2 的文献及理由
## 未命中/待人工补充项
```

## 约束

- **不得编造**专利号或文献；每条须对应可说明的来源
- 公开日晚于本案申请日/优先权日的，标注「不构成现有技术」供下游 novelty worker 使用
